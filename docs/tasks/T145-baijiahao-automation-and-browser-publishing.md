# T145：百家号自动生成、质量门禁与服务器托管浏览器发布

- 状态：已完成
- 决策：ADR-0028
- 类型：v2.1 冻结任务完成后的新增功能

## 目标

交付 `official_site_derived | independent` 两种百家号内容来源、独立机器质量闭环、自动排期、服务器托管浏览器扫码登录、幂等发布、未知态核验和平台审核状态同步。官网现有自动化表与每日十篇行为保持不变。

## 交付物

1. Contracts：策略、会话、运行、事件、错误和 API Schema。
2. 数据库：百家号策略、运行、每日批次、条目、浏览器会话及必要索引、约束和触发器。
3. AI Worker：官网成功事件派生、适用性判断、百家号定向改写、质量门禁、三次重写和独立候选。
4. Browser Worker：扫码会话、加密状态、页面签名、填充、素材上传、提交、未知态核验和审核同步。
5. Publisher：现有 Baijiahao Adapter 接入浏览器网关，API 成功事实事件和百家号终态投影。
6. API/Web：百家号策略、今日进度、扫码登录、重新认证和需人工状态提示。
7. 运维：Compose、环境变量、健康检查、日志脱敏、运行手册和灰度/回滚说明。

## 验收映射

1. 不迁移或改名任何官网自动发布表。
2. 官网自动化与每日十篇回归测试完全通过。
3. 策略只接受 `official_site_derived | independent`。
4. 派生模式只读取已成功 API 发布且有 URL 的官网版本。
5. 派生模式不创建新选题、不重新检索资料，只进行百家号定向改写。
6. 不适合百家号的来源记录为 `skipped`，不得强制同步。
7. 来源版本、URL、引用、派生版本、相似度、质量报告和发布尝试可追溯。
8. 百家号门禁不弱于 ADR-0028，最多重写三次。
9. 浏览器登录不保存密码，状态加密且租户/账号隔离。
10. 同一账号并发为一；验证码、风控、登录失效和页面变化均失败关闭。
11. 未知发布状态先核验再重试，不得生成重复文章。
12. 同一来源版本、百家号账号和策略最多创建一个派生运行。
13. 发布提交后持续同步审核状态和 URL。
14. 百家号失败不修改官网内容、官网自动化运行和官网每日批次。
15. 日志、API、审计和测试快照不包含 Cookie、二维码令牌或凭证。
16. 浏览器 E2E 只访问本地仿真百家号页面。
17. 单元、契约、迁移、PostgreSQL 集成、浏览器 E2E、安全和故障恢复测试通过。
18. 自审、提交并推送当前分支。

## 验证结果

- 单元、契约、集成、安全、故障恢复、OpenAPI、类型检查和 ESLint 通过。
- PostgreSQL 全新数据库迁移通过，迁移序号为 `0041`，当前可执行表数为 72。
- Web 生产构建、Compose 配置和仅访问本机仿真页面的 Playwright E2E 通过。
- 未访问生产官网或生产百家号。

## 禁止项

- 不降低冻结质量门槛。
- 不由服务端伪造模型结论。
- 不绕过验证码或账号风控。
- 不以空实现、假成功状态或生产页面调用完成测试。
