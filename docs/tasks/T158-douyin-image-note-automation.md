# T158：抖音图文作品生成与托管浏览器发布

- 状态：已完成
- 决策：ADR-0073
- 类型：v2.1 冻结任务完成后的新增功能

## 目标

将抖音从“口播脚本包导出”扩展为可生成、质检、渲染、排期、发布和对账的多页图文作品链路，同时
保留旧脚本包兼容能力。

## 交付物

1. Contracts/Skills：`image_note` 卡片结构、Prompt Patch、质量规则和事件。
2. Render/Delivery：确定性图文载荷、图片清单、旧脚本包兼容导出和浏览器网关协议。
3. Media：1080×1440 卡片模板、溢出检查、哈希、对象存储和素材关联。
4. Database：抖音会话、发布、诊断表及浏览器平台自动化约束。
5. Browser Worker：扫码登录、图文上传、文案、AI 声明、提交和内容管理页对账。
6. API/Web：账号登录、重认证、自动化配置、状态和人工恢复入口。
7. Publisher/Infra：提交、轮询、幂等、未知态恢复、Compose 和 Windows 部署配置。

## 验收

1. 不降低冻结质量门槛，不伪造模型或远端状态。
2. 新图文内容输出 5–10 张确定性卡片；旧脚本内容继续可导出。
3. 卡片不存在文本溢出、其他企业品牌、二维码、联系方式或模板新增事实。
4. 同一账号并发为 1，登录状态加密保存，验证码和风控失败关闭。
5. 未知提交先核验后重试，多条匹配必须人工处理。
6. 单元、契约、迁移、类型检查、构建和本地仿真浏览器 E2E 通过。
7. 自审、提交并推送独立功能分支；真实发布另行取得用户确认。
