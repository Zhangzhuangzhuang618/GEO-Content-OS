# T160：资料有效期修正

- 状态：已完成
- 决策：ADR-0075
- 类型：资料维护能力补充

## 目标

允许授权成员在资料详情安全修正录入错误的有效期，避免通过失效和重新导入制造无关解析副作用。

## 交付物

1. Contracts：有效期更新请求、返回契约和公开端点目录。
2. API：租户隔离、资料管理权限、`If-Match` 乐观锁、日期校验和原子审计。
3. Web：详情页修改入口、日期输入、错误提示和更新后即时回显。
4. 基线：OpenAPI/SDK 更新，公开端点数从 169 调整为 170，Release static gate 同步。
5. 测试：契约绑定、成功修改、反向日期、无权限、版本冲突、无解析副作用和界面交互。

## 验收

1. 普通资料支持开放区间，保险证明仍要求完整起止日期。
2. 成功修改不改变内容哈希、资料状态、解析任务、分块、事实或历史引用。
3. 审计记录包含修改前后资料视图及原因；并发覆盖返回 `VERSION_CONFLICT`。
4. 相关单元、契约、集成、Playwright、OpenAPI、Web 构建、格式和静态发布门禁通过。
5. 不在本任务中修改生产数据或部署生产。
