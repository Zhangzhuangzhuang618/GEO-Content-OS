# T151：列举网分类信息生成与托管浏览器发布

- 状态：已完成（真实发布已验证）
- 决策：ADR-0035
- 类型：v2.1 冻结任务完成后的新增功能

## 目标

将列举网接入普通内容生成、质检、审核、排期、合规配图、QQ 扫码会话、分类信息发布和审核状态对账链路。

## 交付物

1. Contracts/Skills：第九个平台、30 字标题预算、列举网 Prompt Patch 和事件。
2. Render/Delivery：确定性分类信息载荷、导出包与浏览器网关协议。
3. Database：列举网规则、会话、发布和诊断制品表。
4. Browser Worker：QQ 扫码、广州生活服务/搬家表单、图片、账号发布配置、提交和会员中心对账。
5. API/Web：列举网账号配置、扫码登录、重新认证、验证码/套餐提示和后台跳转。
6. Publisher/Outbox：提交、待审核轮询、终态投影、未知态恢复和幂等。
7. Infra：Docker、Compose、Windows 部署变量和健康检查。

## 验收

1. 不降低任何冻结质量门槛，不伪造模型或平台结论。
2. 标题 5–30 字、正文至少 600 字，联系方式不进入模型生成内容。
3. QQ 扫码会话和账号配置沿用现有凭证加密与租户隔离边界。
4. 同一账号浏览器并发为 1；验证码、免费额度和页面变化失败关闭。
5. 图片最多 1MB 且不得包含二维码或联系方式；违规图片不得上传。
6. 未知提交先核验后重试；重复匹配必须阻断。
7. 只有公开页面可访问且标题匹配，任务才标记已发布；待审核保持 `processing`。
8. 本地仿真 E2E 不访问真实提交接口。
9. 真实发布前由用户确认敏感联系方式和具体内容。
10. 自审、提交并推送当前分支。
