# T146：关键词多搜索意图与自适应管理

- 状态：已完成
- 关联修复：HOTFIX-20260803-02
- 类型：T001～T145 完成后的现有流程优化

## 目标

关键词管理页完整展示项目下的关键词集，关键词搜索意图支持复选并统一显示中文标签；主题规划按关键词与搜索意图组合使用数据，不丢失同一关键词的其他意图。

## 交付物

1. 数据库迁移：为关键词增加非空、去重且只允许四种枚举值的 `intents` 数组，旧数据从单意图回填。
2. 兼容约束：保留内部 `intent` 字段，并强制等于 `intents` 首项。
3. Contracts/API/OpenAPI：关键词输入和输出统一使用 `intents` 数组。
4. Web：关键词集列表读取全部游标页并按条目数量自适应；创建、编辑和批量导入支持多意图；列表使用中文标签。
5. Topic Planner：按关键词与意图组合展开输入，校验输出意图属于所选关键词的有效意图，并拒绝重复主题问题。
6. 测试：覆盖契约、数据库约束、API 往返、主题规划、多页列表、多选创建与编辑、中文展示及关联页面回归。

## 验收标准

1. 既有单意图关键词迁移后数据不丢失。
2. 每个关键词至少一个、最多四个搜索意图，且不允许重复或未知值。
3. 公开关键词 API 不再返回裸 `intent`，统一返回 `intents`。
4. 页面可复选搜索意图，创建后仍以中文显示。
5. 关键词集超过单页限制时全部可见，不依赖固定条目数布局。
6. Topic Planner 能使用同一关键词的多个意图，输出不得引用未选择的意图或生成重复问题。
7. 相关契约、类型、集成、Web E2E、构建、OpenAPI 和代码检查全部通过。
