# T150：搜狐号内容生成与托管浏览器发布

- 状态：已完成
- 决策：ADR-0034
- 类型：v2.1 冻结任务完成后的新增功能

## 目标

将搜狐号接入普通内容生成、质检、审核、排期、自动配图、托管浏览器发布和发布状态对账链路。

## 交付物

1. Contracts/Skills：第八个平台、标题预算、搜狐 Prompt Patch 和事件。
2. Render/Delivery：确定性搜狐载荷、导出与浏览器网关协议。
3. Database：搜狐规则、会话、发布和诊断制品表。
4. Browser Worker：微信扫码、Quill 编辑器、摘要、配图、AI 声明、提交和内容列表对账。
5. API/Web：搜狐账号、扫码登录、重认证、后台跳转和人工状态处理。
6. Publisher/Outbox：提交、审核中轮询、终态投影、未知态恢复和幂等。
7. Infra：Docker、Compose、Windows 部署变量和健康检查。

## 验收

1. 不降低任何冻结质量门槛，不伪造模型结论。
2. 搜狐标题、摘要、结构、AI 声明和非原创规则由版本化规则固定。
3. 登录不保存密码，凭证和租户隔离沿用现有安全边界。
4. 同一账号浏览器并发为 1；验证码和页面变化失败关闭。
5. 未知提交先核验后重试；重复匹配必须阻断。
6. 只有搜狐远端终态为已发布，任务才标记已发布。
7. 本地仿真 E2E 不访问真实发布接口。
8. 自审、提交并推送当前分支。
