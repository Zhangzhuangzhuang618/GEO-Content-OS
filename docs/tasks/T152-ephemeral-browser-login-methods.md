# T152：搜狐号与列举网临时凭据登录

- 状态：已完成
- 决策：ADR-0036
- 类型：v2.1 冻结任务完成后的新增功能

## 目标

在不保存第三方平台明文凭据的前提下，为搜狐号增加账号密码和手机验证码登录，为列举网增加官方用户名密码登录，并保留原有扫码方式。

## 交付物

1. Contracts/API：受约束的登录请求体、无缓存响应和内部 Worker 转发。
2. Web：搜狐微信/密码/手机三种入口；列举网 QQ/密码两种入口；敏感字段请求后清空。
3. Sohu Worker：真实账号字段、协议确认、人工图形码、短信发送和短信码验证。
4. Lieju Worker：真实用户名密码表单登录且关闭 30 天自动登录。
5. 测试：请求不回显敏感字段、storage state 不含登录输入、旧扫码链路回归。

## 验收

1. 不新增数据库迁移，不持久化账号、密码、手机号或验证码。
2. 发送短信只能由用户明确点击触发，不自动重试。
3. 图形验证码由用户查看和输入，不自动识别或绕过。
4. 列举网不展示平台不存在的短信登录。
5. 两套 Worker 单元与本地 Chromium 仿真、Contracts、API 类型检查和 Web 生产构建通过。
6. 自审、提交并推送当前分支。
