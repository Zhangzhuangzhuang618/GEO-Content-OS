# T147：关键词表格预检与异步分批导入

- 状态：已完成
- 日期：2026-08-03
- ADR：ADR-0029
- 前置：T146

## 目标

让 STR-04 可安全导入结构化 XLSX 关键词库，在不突破冻结搜索意图、不一次性激活机械长尾词的
前提下完成预检、确定性归并、筛选、异步分批入库和进度查询。

## 交付物

1. 0043 数据库迁移、Drizzle Schema 和事件契约。
2. XLSX 解析、表头识别、19 类业务意图映射及确定性词簇归并。
3. 预检、确认、状态查询及关键词服务端分页 API。
4. Knowledge Worker 分批、幂等、可恢复导入。
5. STR-04 上传、预检摘要、分类筛选、导入选项、进度和分页界面。
6. Contracts、解析器、Worker、API 集成和 Web E2E 测试。

## 验收标准

以 ADR-0029“验收”章节为准。完成后更新状态为“已完成”。
