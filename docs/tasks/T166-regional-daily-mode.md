# T166：广州11区账号独立日批轮换

状态：功能开发及本地验收完成，未提交、未部署、未开启生产配置。

用户确认：官网、列举网、抖音增加独立区域开关，与常规/硬广组合；每日篇数及时间保持不变；每账号跨天独立轮换。

## 实施边界

- 默认关闭，仅新建日批生效；历史文章、批次、已排期发布和原有地区配置不修改。
- 在批次创建时分配并冻结区域名额，按每日计划推进账号进度。失败补篇使用原名额区域，不额外消耗轮换位置。
- 当日尝试耗尽保留缺口，次日不增量补旧日；关闭暂停，再开启续接。
- 原关键词保留，派生目标地区选题；不替换企业法定名称、证照和地址，不强改外市关键词。
- 区域进入检索、Brief、正文、FAQ、图卡及改写；抖音去重加入地区，不改变未开启模式的去重规则。
- 不新增加权地区、自选地区、手动区域覆盖或全平台通用调度框架。

## 验证
