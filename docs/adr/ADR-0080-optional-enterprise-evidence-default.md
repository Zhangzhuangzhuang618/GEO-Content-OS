# ADR-0080：企业基础资料默认可选

- 状态：已批准实施
- 日期：2026-09-02
- 任务：HOTFIX-20260902-01
- 影响范围：官网、列举网、Content Writer、Publisher
- 前置决策：ADR-0078

## 背景

ADR-0078 将搬家行业的营业执照、运输许可、运输证、三项体系认证和保险资料纳入独立基础资料通道，
但实现又把“至少存在一份已分类资料”设为所有企业的统一生成与发布前置条件。后续租户可能属于其他
行业，也可能尚未配置这些可选资料；用搬家行业资料类别阻止其官网和列举网日批不符合多租户产品边界。

## 决策

1. 默认不要求企业上传任一固定类别的证照、认证、保险或保障资料。
2. 当前企业存在有效且获准用于文章的基础资料时，官网和列举网继续加载全部资料，确定性生成资质保障
   内容并完成全部引用映射。
3. 当前企业没有基础资料时，不创建资质保障内容块，也不创建对应引用映射；生成和发布可以继续，但
   模型不得补造证照、认证、保险或赔付事实。
4. `enterprise_evidence_required_kinds` 继续作为工作区显式选择的完整性策略。只有工作区主动配置后，
   缺少指定类别才停止生成和发布。
5. 唯一法定企业名称、资料主体匹配、有效期、公开授权、客户化表达和内部话术阻断规则保持不变。

## 验收

- 无基础资料且未配置必需类别的官网、列举网任务可以生成并发布。
- 有基础资料时仍完整插入资质保障内容和引用映射。
- 显式配置必需类别后，缺失资料仍被生成与发布门禁阻断。
- 不出现跨企业引用、虚构资质或内部风控话术。
