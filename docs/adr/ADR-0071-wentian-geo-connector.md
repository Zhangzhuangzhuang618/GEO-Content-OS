# ADR-0071：问天GEO薄连接器

- 状态：已批准实施
- 日期：2026-08-23
- 任务：T157
- 契约：`wentian-geo-connector@1`

## 决策

1. 问天保持完全独立部署，GEO只提供项目连接状态、绑定申请、一次性进入问天和问题集同步。
2. GEO后端使用服务端连接器凭证调用问天Integration API；浏览器不接触连接器密钥，不共享Cookie、数据库、Redis、对象存储或Provider凭证。
3. GEO管理员发起绑定，问天管理员选择本地项目批准；GEO不能按名称猜测或单方激活binding。
4. 首版交付项目绑定、60秒一次性登录和问题集不可变快照同步；Webhook事件回传后置，不作为T157验收依赖。
5. 问天不可用时GEO核心功能继续运行；GEO项目删除或连接器解绑不得删除问天项目和历史数据。
6. 服务端请求执行签名、契约版本、时间窗、nonce、请求ID和幂等校验；凭证只通过部署环境注入。

## 数据与权限

- GEO只保存外部binding引用、最近同步结果和不含回答正文的连接状态；
- 只有当前租户和项目管理员可以申请、撤回、同步或断开；普通成员只能查看状态并申请一次性进入票据；
- 问天项目成员关系和binding active状态共同决定最终访问权限。

## 验收

- 错租户、错项目、错角色、错签名、重放和非active binding全部失败关闭；
- 相同问题集修订重复同步不产生不同问天快照；
- launch code不能在GEO前端日志或持久状态中保存；
- 问天停机不影响GEO其他页面、任务和队列；
- Contracts、API、Web、迁移、OpenAPI和专项测试通过。
