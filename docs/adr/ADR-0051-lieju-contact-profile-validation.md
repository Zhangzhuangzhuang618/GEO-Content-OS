# ADR-0051：列举网发布资料按平台现行格式校验并允许显式清空

- 状态：已批准实施
- 日期：2026-08-19
- 任务：HOTFIX-20260819-03
- 影响范围：列举网官方 API Adapter、平台账号 API、发布管理 Web
- 延续决策：ADR-0038、ADR-0046、ADR-0047

## 已核验事实

同一个列举网 API Key 在不同 GEO 平台账号中不代表请求内容相同。每个账号独立保存加密发布资料，
官方 API 请求会同时发送联系人、电话、QQ 和微信号。

生产失败响应的规范化 SHA-256 为
`7653da8c876cf149a0c97b3a85669a1bcd952740cfd2dd4ca77eaf0663398c61`。该响应与列举网当前发布页的
精确提示“请正确填写微信号，打开微信右下角‘我’，头像右侧查看您的微信号”一致，GBK 响应体为
62 字节。这是字段校验拒绝，不是 API Key、浏览器登录态或账号 API 权限问题。

旧编辑页只允许更新 API Key 和地址，无法更新或清空已加密的微信号。因此错误资料会被后续请求
持续继承。

## 决策

1. 列举网浏览器网关和官方 API 共用当前平台格式：电话为 6～12 位数字，或带区号的固定电话；QQ
   为空或 5～15 位数字；微信号为空或以字母开头、只含字母、数字、下划线、减号的 6～20 位字符串。
2. 创建账号、编辑账号和适配器最终配置解析均执行相同校验。错误资料必须在请求外部平台前以
   `PLATFORM_ACCOUNT_CONFIGURATION_INVALID` 明确失败，不能记为发布状态未知。
3. 编辑页允许局部替换区域、地址、联系人、电话、QQ 和微信号；已保存值继续不回显。
4. QQ 和微信号使用独立的显式清空选项。空白输入仍表示“不修改”，避免因页面不回显而误删资料。
5. 列举网返回当前联系方式校验提示时记为 `PUBLISH_REJECTED`，不再归类为发布状态未知，也不触发
   浏览器登录或 API 权限诊断。
6. 不自动修改旧账号凭据，不自动重投旧任务，不改变冻结质量门槛、旧内容或旧质量报告。

## 安全与恢复边界

- API Key 和联系方式仍只以加密凭据保存，不进入账号响应、日志、审计详情或前端初始值。
- 局部更新在服务端与原加密资料合并；未提交字段保持不变，显式空字符串只用于清空可选 QQ/微信号。
- 已产生未知发布结果的旧任务仍须先在列举网后台确认未发布，再使用既有恢复入口；部署不会自动
  推断或重投。
- 无数据库迁移和公开 API 契约变化。

## 验收

- 编辑列举网账号时可以更换必填发布资料，并可分别清空 QQ、微信号。
- 不重新填写 API Key 也能完成发布资料局部更新，原 Key 和其余资料保持不变。
- 不合法电话、QQ 或微信号在前端和适配器配置层均被拒绝。
- 旧错误资料在发出外部请求前明确失败，不占用未知态人工对账。
- 精确微信号校验响应被识别为明确拒绝，且只发送一次请求。
- 页面、请求层、服务端加密合并、Adapter 和 Publisher 状态落盘均有回归测试。
