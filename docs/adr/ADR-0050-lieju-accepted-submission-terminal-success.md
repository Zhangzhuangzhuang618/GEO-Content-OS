# ADR-0050：列举网明确受理即完成 GEO 发布任务

- 状态：已批准实施
- 日期：2026-08-19
- 任务：HOTFIX-20260819-01
- 影响范围：列举网官方 API Adapter、列举网托管浏览器 Worker、Publisher 状态输入
- 修订决策：ADR-0038 第 6、7 条及“不做”第 3 条，HOTFIX-20260818-07

## 已核验事实

列举网浏览器提交成功后显示精确确认文本“信息审核中！”。列举网官方 API 成功响应会返回
“信息发布成功”，并可能同时返回内容 ID 和详情 URL。两条路径都表示平台已经接受本次提交，后续由
列举网进行内容审核。

官方 API 没有状态查询接口。若将明确成功响应保存为 `processing`，Publisher 会把任务永久保留在
`publishing`，也不会生成可执行的自动对账事件。浏览器确认页此前同样被解释为 `processing`，与产品
要求“进入信息审核中页面即视为发布成功”不一致。

## 决策

1. 对列举网，GEO 的发布终态表示“列举网已明确接受提交”，不表示内容已经通过列举网审核或已公开
   展示。
2. 浏览器仅在出现精确文本“信息审核中！”时返回 `published`；不再等待会员内容列表出现标题。
3. 官方 API 仅在通过既有明确成功语义校验后返回 `published`；不再以公开页即时可访问作为完成条件。
4. 明确拒绝、验证码、登录失效、HTTP 5xx、网络未知和无法识别的响应继续按原规则失败关闭或转人工
   核实，不得推断为成功。
5. 本决策只改变列举网提交完成语义，不改变其他平台、不修改冻结质量门槛，也不重新评估旧内容或旧
   质量报告。

## 历史任务

已经停在 `publishing` 的官方 API 任务保存了内容 ID 或 URL，不得因部署自动重新提交。部署后可使用
现有“确认已经发布”入口按保存的列举网 URL 完成一次性收尾；新任务会直接进入终态成功。

## 验收

- 浏览器出现精确审核确认页后返回 `published`，且不查询会员标题列表。
- 官方 API 返回明确成功语义后返回 `published`，不额外请求公开详情页。
- 无法识别、拒绝、登录和验证码响应仍不会被误判成功。
- Publisher 收到结果后完成发布任务、内容变体和自动化批次状态。
