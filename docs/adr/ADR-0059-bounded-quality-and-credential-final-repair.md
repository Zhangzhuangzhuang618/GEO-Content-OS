# ADR-0059：品牌质检与证照重写的条件式最终修复

- 状态：已批准实施
- 日期：2026-08-20
- 任务：HOTFIX-20260820-07
- 影响范围：Quality Checker、Content Writer、AI Worker
- 延续并修正：ADR-0040、ADR-0043、ADR-0049、ADR-0057、ADR-0058

## 已核验事实

HOTFIX-20260820-06 部署后，生产重新质检 8 个列举网旧候选。3 个任务在首次语义修复后仍仅返回
不可验证的 `brand.other_company_name`，原因分别为未引用准确名称、引用名称不在声明位置、引用
内容不可识别为企业名称。现有运行时直接失败，模型没有机会根据第二次新出现的原因纠正输出。

另外 5 个任务已经通过品牌校验并进入质量重写，但 Content Writer 在既有确定性修正后仍保留没有
通过 `citation_map` 逐项绑定冻结证照的资质声明，随后进入人工处理。旧候选的重写继续读取首次生成
事件中的不可变 Writer 输入；部署后新增资料不会进入这些候选。

## 决策

1. Quality Checker 保留既有首次完整语义修复。仅当该修复结果再次以脱敏拒绝列表失败，且列表中
   每一项都属于 `brand.other_company_name` 时，再允许一次最终完整语义修复。最终修复只接收第二次
   拒绝原因和原始冻结输入；不得删除问题、重算模型分数或由服务端生成通过结论。
2. 最终品牌修复仍执行完整 Schema、GEO 分数、decision、事实、标题、citation 和问题可核验性断言；
   仍无效时立即失败并进入人工处理。非品牌语义错误继续维持一次修复上限。
3. 搜狐号或列举网的质量引导重写在既有确定性修正后，如果内容结构已经合格，剩余问题仅为证照
   `citation_map` 绑定失败以及可能同时存在的“重写未变化”，允许一次最终定向重写。
4. 最终证照重写只使用候选冻结输入：存在已授权结构化证照引用时，每项声明必须关联能直接证明该
   资质且主体匹配的输入 citation ID；没有引用或不能完整证明时，必须从母稿和平台稿删除对应声明。
   不得编造引用、借用当前新资料或由服务端静默改写正文。
5. 最终重写后继续执行全部内容质量与确定性证照校验；仍不合格时保持失败关闭。模型调用只在上述
   两种已经发生第二次可纠正失败的条件下增加一次，不扩大普通生成、普通质检或其他错误的调用数。

## 兼容性与恢复边界

- 不修改质量分、BLOCK、事实、品牌、平台适配或证照证据门槛。
- 不重新检索、重算或覆盖旧候选、旧 Writer 输入和旧质量报告。
- 无数据库迁移、公开 API、Web 页面或发布状态机变更。
- 历史人工处理任务不会因部署自动恢复；必须显式重新质检，缺少冻结证照时应发起新的日批尝试。

## 验收

- 第二次仅出现品牌问题格式拒绝时最多再修复一次，第三次合法则继续质检，仍无效则停止。
- 第二次包含非品牌语义错误时不得增加调用。
- 浏览器平台旧候选没有冻结证照时，最终重写删除资质声明且不伪造引用；仍保留声明时继续失败。
- 有冻结授权证照时仍必须逐项绑定；错主体、缺项、未授权或过期证照继续阻断。
- Skills、AI Worker、类型检查和全量回归通过。
