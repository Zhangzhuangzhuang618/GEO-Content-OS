# ADR-0040：质检输出矛盾校验与不可重试失败收尾

- 状态：已批准实施
- 日期：2026-08-17
- 任务：HOTFIX-20260817-07
- 影响范围：所有平台共用的 Quality Checker 与日批自动化
- 前置决策：ADR-0013、ADR-0027、ADR-0037

## 背景

列举网日批出现结构合法但语义矛盾的模型输出：平台规则使用 `title_max_characters`，共享质检仅识别
`title_max_length`，因此无法确定性校验标题限制；模型还可能从 few-shot 复制不存在的高风险事实问题。
运行时已按 ADR-0027 在同一次执行中进行一次语义修复，但修复后仍无效时，队列仍重复整个质检调用，
造成候选长时间停在 `quality_check`。

## 决策

1. 共享质检同时识别 `title_max_length` 与 `title_max_characters`，统一按 Unicode 字符计数。
2. 标题超过硬限制而没有标题 `BLOCK` 时拒绝输出；标题未超过限制却返回对应标题长度 `BLOCK` 时也
   拒绝输出。服务端只验证模型结论，不代替模型生成通过结论。
3. 语义修复提示显式列出允许使用高风险事实规则的 `claim:<claim_key>`；没有符合条件的事实时，禁止
   使用两个高风险事实规则 ID，避免复制 few-shot 结论。
4. ADR-0027 规定的一次进程内语义修复保持不变。修复后仍返回 `SKILL_OUTPUT_INVALID` 时，当前生成
   运行立即失败，对应自动化运行进入 `manual_required`，日批候选按各平台既有规则退役或进入人工
   处理，不再重复队列级模型调用。
5. 其他错误继续使用既有队列重试与终态策略；本决策不扩大未知数据库或基础设施错误的行为变更。

## 不变项

- 不降低冻结质量分、BLOCK、事实、品牌或平台适配门槛。
- 不修改、重算或覆盖旧内容版本与旧质量报告。
- 不由服务端伪造模型质量结论，也不因模型输出无效而自动放行。
- 不新增公开端点、数据表或部署配置。

## 验收

- `title_max_characters` 的超限和矛盾阻断均有确定性回归测试。
- 没有高风险事实时，语义修复提示明确禁止对应规则；存在时只允许精确 claim 位置。
- 语义修复后仍无效的质检输出在第一次队列执行后进入人工处理；其他错误保持既有队列策略。
- Skills、AI Worker、数据库集成、类型检查和全量回归通过。
