# ADR-0049：企业名称策略按当前租户隔离并聚合质检重判诊断

- 状态：已批准实施
- 日期：2026-08-18
- 任务：HOTFIX-20260818-08
- 影响范围：所有平台共用的内容生成、Quality Checker 与确定性品牌扫描
- 前置决策：ADR-0014、ADR-0040、ADR-0041、ADR-0043

## 背景

共享企业名称策略曾把“广州志远搬家服务有限公司”写成全局唯一允许名称。另一个企业运行列举网
日批时，其已发布品牌档案中的本企业名称因此被当作第三方名称；模型还可能在同一份质检输出中同时
产生错误品牌位置、虚构联系方式或无对应声明的高风险事实问题。既有断言只返回第一个失败原因，
一次完整语义重判修正首项后，第二项才暴露并使运行进入 `QUALITY_CHECK_EXECUTION_FAILED`。

问题单建议由服务端省略无法核验的问题并继续质检。该方案会让服务端修改模型问题集合并间接改变
分数或决策，违反冻结质量边界，因此不采用。

## 决策

1. 内容生成、共享 Quality Checker 和确定性品牌扫描均从当前运行已发布的品牌档案读取本企业法定
   名称，不再把任一企业名称作为其他租户的默认允许值。
2. 本企业名称只从正向第一方字段 `positioning` 与 `cta` 提取；禁止词、差异化说明等可能包含竞品
   的字段不得进入允许列表。若档案没有可识别的完整法定名称，则不允许任何可识别企业名称，继续
   失败关闭。
3. 第三方名称规则保持不变：内容中真实存在的其他企业、品牌、平台或数据提供方名称继续形成
   `brand.other_company_name` BLOCK；行业泛称与匿名描述继续不视为专有名称。
4. 一次质检输出中，品牌、列举网联系方式与高风险事实问题的全部可核验性断言失败都聚合为脱敏
   拒绝列表，包含规则、分类、严重级别、位置和稳定原因码；不得记录模型原始消息、正文或凭据。
5. ADR-0040/0043 规定的一次完整模型重判同时接收全部拒绝原因。模型必须重新返回完整质量结果；
   服务端不得删除问题、替换分数或重算决策。重判后仍无效时继续进入人工处理，不增加第三次调用。
6. 列举网联系方式问题仅在声明位置含字面电话号码、网址、微信 ID 或 QQ ID 时可核验；高风险事实
   问题仍只能指向输入中真实存在且风险与裁决均符合门槛的 `claim:<claim_key>`。

## 不变项

- 冻结 GEO、事实、品牌、可读性、平台适配、BLOCK 与告警门槛不变。
- 最多三次内容重写、一次质检语义重判和失败转人工规则不变。
- 旧内容版本、旧质量报告和旧运行不修改、不重新评估；部署后需显式重新发起失败候选或日批尝试。
- 无数据库迁移、公开 API、Web 页面或发布状态机变更。

## 验收

- 当前企业名称在生成、质检和确定性扫描中均被视为第一方，另一租户名称仍被阻断。
- 未声明本企业法定名称时不回退到历史硬编码名称。
- 同一输出中的品牌、联系方式和高风险事实误报一次性进入脱敏重判提示。
- 真实第三方名称、真实正文联系方式和真实高风险不支持声明继续 BLOCK。
- Contracts、Skills、AI Worker 的类型检查、单元与全量回归通过。
