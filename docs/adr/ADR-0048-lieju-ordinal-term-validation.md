# ADR-0048：列举网普通序数与排名宣传词区分

- 状态：已批准实施
- 日期：2026-08-18
- 任务：HOTFIX-20260818-05
- 影响范围：列举网发布前渲染校验
- 前置决策：ADR-0037、ADR-0038、ADR-0045

## 背景

ADR-0045 放行“第一方”后继续阻断其他全部“第一”表达。生产文章使用“第一步：盘点物品”描述操作
顺序，在发布前渲染阶段被误判为排名宣传并以 `PROHIBITED_TERM` 阻断，实际没有调用列举网官方 API。

“第一步、第一阶段、第一时间、第一年”等表达只描述顺序或时间，不构成排名、极限或结果保证。继续
全局拦截会阻止正常流程型内容发布，也与质量规则只禁止无依据排名宣传的语义不一致。

## 决策

1. 终止 ADR-0045“除第一方外阻断其他全部第一表达”的宽泛规则。
2. 发布层继续阻断明确排名或优越性语境，包括“行业第一、排名第一、第一名、第一品牌、第一选择、
   第一梯队、第一服务商”以及“自称第一、位居第一”等独立排名断言。
3. “第一方、第一步、第一阶段、第一时间、第一年”等普通证据属性、顺序和时间表达不触发禁词。
4. “最好、最佳、首选、权威、国家级、百分百、100%保证”等既有禁止表达保持不变。

## 兼容性与安全边界

- 无数据库迁移、公开 API、Prompt、质量门槛或发布状态机变更。
- 不改写旧内容、旧质量报告和旧发布尝试；部署后由用户显式重试原发布任务。
- 本修正只消除确定性的普通序数误判，不由服务端伪造模型质量结论。

## 验收

- 包含普通序数和时间表达的列举网内容通过渲染校验。
- 明确排名宣传及既有高风险宣传词继续以 `PROHIBITED_TERM` 阻断。
- 列举网渲染契约、Adapter 类型检查和 Publisher 回归通过。
