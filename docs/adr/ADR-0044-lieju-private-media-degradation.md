# ADR-0044：列举网私有媒体降级发布

- 状态：已批准实施
- 日期：2026-08-17
- 任务：HOTFIX-20260817-11
- 影响范围：列举网自动配图、Publisher 与官方 API 发布
- 前置决策：ADR-0030、ADR-0037、ADR-0038

## 背景

列举网内容通过冻结质量门禁并生成私有图片后，Publisher 复用了搜狐号和百家号的媒体字段注入函数，
向列举网严格 `platform_meta` 写入未声明的 `body_asset_ids`，导致发布在渲染阶段以
`PUBLISHER_RENDER_BLOCKED` 失败。当前私有 MinIO 没有持久公网地址，而列举网官方 API 只能通过
HTTPS 图片 URL 引用图片，因此这些列举网配图无法实际交付。

## 决策

1. 列举网使用独立媒体注入逻辑，只写入其渲染 schema 已声明的 `cover_asset_id`；
   `body_asset_ids` 继续只服务搜狐号和百家号，不放宽列举网严格 schema。
2. 列举网官方 API 配置不附加浏览器网关专用的 `account_id`；列举网浏览器网关、搜狐号和百家号的
   账号作用域保持不变。
3. 当 `GENERATED_MEDIA_PUBLIC_BASE_URL` 为空时，质量通过的列举网自动化直接进入既有排期，不创建
   配图运行、不调用图片规划或生成模型、不写入空用途素材。文章按无图模式发布。
4. 配置持久 HTTPS 媒体地址后，列举网自动恢复既有配图链路，并仅向官方 API 传递有效 HTTPS URL。
5. 图片能力仍不得改变内容质量结论；无图降级不得降低事实、品牌、安全或平台适配门槛。

## 兼容性

- 搜狐号、百家号和官网的配图、上传及降级逻辑不变。
- 无数据库迁移、公开 API 或 Web 变更。
- 旧媒体运行、素材和发布尝试保持原样，不自动改写；现有失败任务需在部署后显式重试。

## 验收

- 带私有封面和正文素材的列举网内容能够通过严格渲染并调用官方 API，且请求中没有图片 URL。
- 列举网官方 API 配置不包含 `account_id`，浏览器网关账号仍包含该字段。
- 无公网媒体地址时列举网不创建配图任务，搜狐号仍正常创建；配置公网地址后列举网恢复配图。
- Publisher、AI Worker、类型检查、契约及集成回归通过。
