# ADR-0022：AI 可见度实验、竞品基准与内容机会闭环

## 状态

已接受。该变更是 v2.1 冻结基线后的增量能力，变更编号为 `CHG-VIS-001`。现有七个平台发布流程、`visibility_observations` 手工观察记录和官网自动发布闭环保持不变。

## 背景

现有数据分析只能录入官网、百家号、头条号、知乎、小红书、微信公众号和抖音的人工观察，不能主动向 AI 模型发起版本化问题集测试，也不能保留原始回答、计算品牌可见度、比较竞品或把零命中问题转化为内容机会。

GEOVisibilityTool 的六类意图、三十问、品牌提及/认知/排名/情感评分方法具有产品参考价值；GEOFlow 的可追踪工作流与确定性检查具有工程参考价值。但浏览器 DOM 自动化、单站点数据模型和启发式分数不能直接作为企业 SaaS 的生产核心。

## 决策

### 边界

- 新增独立的 `ai_visibility_*` 数据域，不复用内容发布平台的 `platform_code`；
- 首期运行时只启用现有 DeepSeek Adapter，契约保留其他 AI 引擎代码但 UI 不宣称其已可用；
- 使用真实模型 API 和 `geo-ai` 队列异步运行，不使用浏览器模拟 AI 产品页面；
- `model_only` 结果衡量模型记忆与回答倾向，不宣称等同于联网搜索结果；
- 分数是版本化内部基准，不宣称为行业标准；
- 原始回答和逐题结果只追加，不覆盖历史；运行汇总允许从排队推进到终态。

### 问题集

- 默认问题集由六类意图各五题组成：品牌认知、探索、推荐、比较、科普、采购；
- 仅品牌认知题允许出现目标品牌名或别名；其余二十五题禁止夹带目标品牌，避免把“被点名回答”误算为自然可见度；
- 默认问题由确定性模板生成，避免为了生成测试问题额外引入模型幻觉；
- 问题集保存品牌名、别名、行业、市场、定位和竞品名单；
- 问题集采用 `series_id + revision` 版本标识。历史运行固定引用创建时的不可变问题集版本。

### 运行和评分

- 一个运行只对应一个问题集版本、一个 AI 引擎和一个模型；
- API 创建运行和 Outbox 事件必须处于同一事务；重复请求由现有幂等层阻止重复运行；
- AI Worker 保存逐题原始回答、模型请求 ID、Token 用量、回答哈希和可核验 URL；
- 评分 `ai-visibility-score@2`：自然提及率 40%、正确品牌认知率 30%、明确排名 20%、正向情感率 10%；推荐率作为独立诊断指标展示；
- 自然提及率只使用探索、推荐、科普和采购题，排除品牌认知题与比较题；品牌认知回答区分正确识别、未识别、疑似误认和不确定；
- 排名只接受回答中明确的“第 N 名/位”或有序列表位置，不再根据品牌在文本中首次出现的顺序猜测；
- 内容机会必须同时满足高商业价值、目标品牌未自然出现、至少一个竞品出现；只有目标品牌和竞品都未出现的问题不列为竞品机会；
- 竞品、来源、零命中商业问题和前后对比均从原始逐题结果重新计算，汇总保存评分版本；
- 来源同时按域名和具体 URL 汇总，并保留命中的问题数与意图；模型未给出 URL 时明确显示“无可核验网址”；
- 高价值零命中问题通过 UI 预填现有“创建内容”流程，不绕过 Brief、质量检查和平台流程。

### 接口

- `POST /ai-visibility/query-sets`：创建不可变问题集版本；
- `GET /ai-visibility/query-sets`：按工作空间/项目查询；
- `POST /ai-visibility/runs`：为所选启用引擎创建异步运行；
- `GET /ai-visibility/runs`：查询运行历史和趋势摘要；
- `GET /ai-visibility/runs/{id}`：读取逐题回答、证据、竞品和内容机会。

以上接口均要求 `analytics.read` 和 `analyst_or_admin`，写接口要求幂等键。

### 可靠性与安全

- 每题模型调用沿用 Adapter 的超时和重试；单题失败不会丢失其他题结果；
- 运行终态为 `succeeded`、`partial` 或 `failed`；至少一个逐题结果成功即可形成可解释的部分报告；
- 租户、工作空间和项目由数据库复合外键与服务层校验双重隔离；
- API Key 继续只从 Worker 环境变量读取，不写入数据库、接口响应或日志；
- 回答中的 URL 仅作为“模型回答中出现的链接”保存，不自动认定为事实来源；
- 原始回答可能包含第三方内容，UI 默认折叠，导出和日志不得批量回显凭证或隐私数据。

## 数据与事件影响

- 新增 `ai_visibility_query_sets`、`ai_visibility_queries`、`ai_visibility_runs`、`ai_visibility_responses`；
- 新增事件 `analytics.visibility.probe_requested.v1` 和聚合 `visibility_run`；
- 迁移增至 0038；表数由 59 增至 63；
- 第一批新增 5 个公开 API，公开 API 数由 127 增至 132。

## 明确不做

- 不抓取或自动登录 ChatGPT、元宝、豆包、文心一言等网页；
- 不伪造搜索引用，不把无联网能力的模型结果标记为联网结果；
- 不自动采购或配置第三方 AI 搜索 API；
- 不更改七个平台内容生成、审核、发布状态机；
- 不自动发布可见度机会生成的内容；
- 首期每个问题只运行一个样本，不实现多次采样、置信区间或跨模型统计显著性检验。
