# ADR-0058：质检器允许名称重复误报恢复

- 状态：已批准实施
- 日期：2026-08-20
- 任务：HOTFIX-20260820-06
- 影响范围：Quality Checker、AI Worker
- 延续决策：ADR-0049、ADR-0057

## 已核验事实

HOTFIX-20260820-05 部署后，生产重新质检 9 个旧列举网候选。其中 7 个任务的 Quality Checker
先后两次输出 `brand.other_company_name`，服务端两次均确认被引用的名称只是当前企业已发布名称或
明确允许的匿名称谓，并以 `only_allowed_owner_or_generic_name_is_quoted` 拒绝该问题。第二次模型
输出仍被严格校验异常终止，导致任务在进入后续确定性风险扫描前被标为人工处理。

另外 2 个资质问题来自修复部署前创建的旧候选，其冻结引用为空；重新质检不会重新检索后来上传的
证照。这属于既有不可变证据边界，不是本 ADR 的修复范围。

## 决策

1. Quality Checker 首次输出继续执行完整语义校验；失败后仍只允许一次独立模型语义修复。
2. 仅在第二次模型输出中，若 `brand.other_company_name` 被服务端精确判定为
   `only_allowed_owner_or_generic_name_is_quoted`，删除该条不可验证问题，并根据剩余模型问题和冻结
   warning 门槛重新计算 `decision`。模型分数和服务端提供的 GEO 分数均不得改写。
3. 恢复只适用于当前租户已发布品牌资料中的本企业名称，以及规则明确列举的匿名称谓。没有精确
   引用、位置无效、分类或严重度错误、引用内容不能确定为普通表述等其他语义错误继续失败，不得
   借此放行可能真实存在的第三方品牌。
4. 恢复后的结果仍必须进入原有确定性风险扫描。正文中的真实法定企业名称和受支持的具名平台继续
   生成品牌 BLOCK；模型返回的、能够在准确位置验证的第三方名称问题继续保留。
5. 高风险事实、资质证据、联系方式、标题限制、未知 citation、注入和其他冻结门槛不采用此恢复，
   原有失败与阻断行为保持不变。

## 兼容性与恢复边界

- 不新增模型调用、数据库迁移、公开 API 或前端契约。
- 不把服务端结果伪装成新的模型结论；最终质量报告仍由模型有效问题与服务端确定性问题合并生成。
- 不自动重评历史内容或质量报告。旧候选必须由用户显式重新质检；需要新企业资料时仍须发起新批次。

## 验收

- 同一本企业名称或允许匿名称谓连续两次被模型误报时，质检任务不再因
  `SKILL_OUTPUT_INVALID` 进入人工处理。
- 真实第三方品牌仍然 BLOCK；分类错误等不能安全证明为误报的问题仍然失败。
- 资质、事实、标题和平台合规硬规则保持原门槛。
- Quality Checker、AI Worker 及全仓质量门禁通过。
