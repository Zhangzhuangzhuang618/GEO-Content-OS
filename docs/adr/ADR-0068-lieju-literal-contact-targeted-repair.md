# ADR-0068：列举网字面联系方式统一检测与定向修复

- 状态：已批准实施
- 日期：2026-08-22
- 任务：HOTFIX-20260822-01
- 影响范围：列举网生文、质量重写、确定性质检与发布前校验
- 前置决策：ADR-0037、ADR-0041、ADR-0056、ADR-0061、ADR-0062

## 已核验事实

生产列举网候选在连续三次质量重写后仍保留 `www.gsxt.gov.cn` 和 `ysfw.mot.gov.cn`。当前确定性
质量扫描能识别带协议或 `www.` 的网址，但不能识别无协议裸域名；Content Writer 的最终定向修复
只覆盖无证据证照声明和禁止宣传词，整篇模型重写即使重复保留网址也不会进入精确修复。最终报告
因此持续命中 `deterministic.lieju.external_url_forbidden`，并在达到重写上限后进入人工处理。

## 决策

1. Contracts 提供唯一的列举网字面联系方式检测器，统一识别带协议网址、`www.` 网址、常见裸域名、
   中国手机号、固话及带具体值的微信或 QQ 账号。中性的官方渠道名称和“通过页面联系方式咨询”继续
   放行。
2. Content Writer 在生成及质量重写后使用同一检测器。整篇重写后若剩余问题只包含列举网具体联系
   方式或网址、既有证照或宣传词问题及内容未变化，可进入 ADR-0061 的最多两轮定向文本修复。
3. 定向修复只返回被命中字段的替换文本。网址出现在证照核验说明中时，保留官方渠道名称与核验动作，
   删除域名；服务端拒绝缺失、未知、重复、空白、未变化或仍含任一具体联系方式或网址的替换结果。
   锁定区块仍不得修改。
4. Quality Checker 输入语义约束与 AI Worker 确定性质检按真实字段位置识别列举网联系方式问题；
   列举网 Render 发布前校验复用同一检测器，避免生成、质检和发布层规则漂移。
5. 不删除证照核验建议，不放行具体网址，不降低任何冻结分数或 BLOCK 门槛，也不由服务端伪造模型
   质量结论。

## 后果

- 无数据库迁移、公开 API、状态机或 Web 变更。
- 需要重新构建部署 AI Worker 与 Publisher；Contracts 和 Skills 作为构建依赖同步更新。
- 旧内容、旧质量报告、旧批次和旧发布任务不会自动重评。既有人工处理候选需要显式重新质检或发起
  新尝试，才会使用新规则。

## 验收

- `https://...`、`www.gsxt.gov.cn`、`ysfw.mot.gov.cn`、手机号、固话和微信或 QQ 具体账号均被
  统一检测；只写官方渠道名称的核验说明继续通过。
- 生产同型的双网址核验段落在整篇重写仍未修复时进入定向修复，两个域名均被删除，其他内容保持
  不变。
- 定向替换仍残留裸域名时被拒绝，不得进入可发布状态。
- Contracts、Skills、AI Worker、列举网 Render、类型检查、Lint 和全量回归通过。
