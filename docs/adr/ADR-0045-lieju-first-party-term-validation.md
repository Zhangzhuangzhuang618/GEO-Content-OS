# ADR-0045：列举网“第一方”禁词误判修复

- 状态：已批准实施
- 日期：2026-08-18
- 任务：HOTFIX-20260818-01
- 影响范围：列举网发布前渲染校验
- 前置决策：ADR-0037、ADR-0038、ADR-0044

## 背景

列举网渲染校验把任意“第一”子串视为禁止或高风险宣传词。已通过冻结质量门禁的文章使用
“企业第一方确认信息”描述证据边界时，被误判为 `PROHIBITED_TERM`，未调用列举网官方 API。

## 决策

1. 禁词校验中的“第一”不再匹配紧随“方”的“第一方”证据属性表达。
2. 其他“第一”表达以及“最好”“最佳”“首选”“权威”“国家级”“百分百”和“100%保证”继续阻断。
3. 不改变生文、质检、重写、排期或官方 API 提交规则，不降低冻结质量门禁。

## 兼容性

- 无数据库迁移、公开 API、Web 或配置变更。
- 旧内容、旧质量报告和旧发布尝试保持不变；部署后需显式重试原失败发布任务。

## 验收

- 包含“企业第一方确认信息”的合规文章通过列举网渲染校验。
- 包含“行业第一”的文章仍以 `PROHIBITED_TERM` 阻断。
- 列举网渲染契约、类型检查及全量回归通过。
