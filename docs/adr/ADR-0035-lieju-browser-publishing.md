# ADR-0035：列举网分类信息生成与托管浏览器发布

- 状态：已批准实施
- 日期：2026-08-14
- 任务：T151
- 影响范围：`lieju` 普通内容生成、质检、审核、排期和浏览器发布
- 前置决策：ADR-0019、ADR-0020、ADR-0028、ADR-0030、ADR-0034

## 已核验的平台事实

2026-08-14 使用真实广州列举网页面核验：发布流程为“选择分类 → 填写信息 → 提交发布”；商务服务下的物流/货运表单固定入口为 `/5/104`。标题最多 30 字，必须填写区域、物流子类、描述、联系电话和联系人；普通会员最多上传 1 张不超过 1MB 的 JPG/GIF/PNG 图片。图片不得包含二维码、电话、微信等联系方式。

普通会员每天仅有 1 条免费发布额度，免费发布会调用腾讯交互验证码；购买发布套餐或发帖包后页面声明无需验证码。会员中心“管理信息”明确说明内容存在审核期，未审核内容不公开展示。会员中心虽展示 `api_key`，但没有可验证的官方发布 API 文档，因此不得据此构造或宣称官方 API 发布能力。

列举网提供 QQ OAuth 二维码登录。浏览器 Worker 只使用 QQ 扫码建立会话，不保存列举网或 QQ 密码。使用既有用户名账号时，用户必须先在列举网完成 QQ 绑定；否则 QQ OAuth 可能建立另一个列举网账号。

## 决策

列举网作为第九个平台接入普通内容主链路，不新增日批策略。系统生成独立分类信息变体，继续执行冻结质量门禁、人工审核和排期；发布由独立 `workers/lieju-browser` 串行执行。

平台规则固定标题 5–30 字、描述至少 600 字，禁止最高级、排名、竞品贬损、虚假承诺和在标题、描述、图片中写联系方式。发布地址、广州区域、物流子类、联系电话、联系人及可选 QQ/微信属于账号发布配置，不由模型生成；敏感联系方式只以既有凭证信封加密保存且不回显。

浏览器固定选择“商务服务 → 物流/货运”，按账号配置填写区域、街道、物流子类和联系方式，不购买置顶推广，不引用旧信息自动填充。图片必须通过既有机器图像门禁，并在上传前再次检查格式、1MB 上限和二维码；不支持 GIF 动图生成。

验证码、登录失效、免费额度耗尽、账号未绑定 QQ、页面签名变化和平台风控均失败关闭。检测到交互验证码时返回 `manual_required`，不绕过、不代解，也不伪造发布成功。只有账号具有免验证码权益且页面未出现验证码时，才允许无人值守提交。

提交响应不作为发布成功结论。系统先在会员中心“管理信息”按账号、标题和提交时间对账；待审核记为 `processing`。只有管理页提供公开信息链接且公开页面可访问、标题匹配时才记为 `published`。未知状态禁止直接重复点击，必须先对账；多条匹配进入人工处理。

## 数据与接口

- 新增 `lieju_browser_sessions`、`lieju_browser_publications`、`lieju_browser_artifacts`。
- 新增 `lieju.publication.reconcile_requested.v1`。
- 新增列举网登录状态、扫码登录、重新认证 3 个公开端点；可执行端点总数从 150 增至 153。
- `platform_rule_versions` 新增已发布列举网规则；平台枚举扩展为 9 个。
- 列举网发布配置作为平台账号加密凭证的一部分保存，不进入 Prompt、审计快照或日志。

## 明确不做

1. 不根据未文档化的 `api_key` 猜测发布接口。
2. 不破解、代解或自动绕过腾讯验证码。
3. 不自动购买套餐、发帖包、刷新包或置顶推广。
4. 不新增列举网日批，不跳过现有质检与审核。
5. 不把提交完成、会员中心待审核或 Worker 自身判断伪造成平台已发布。

## 上线门禁

单元、契约、迁移、类型检查、页面仿真 E2E、验证码阻断、未知态和重复匹配测试必须通过。首轮只允许单账号、串行、每天最多 1 条真实灰度；真实提交必须由用户明确授权并确认联系人、联系电话、区域、地址和物流子类。
