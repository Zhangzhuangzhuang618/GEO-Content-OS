# ADR-0052：Publisher 按当前企业资料校验官网企业名称

- 状态：已批准实施
- 日期：2026-08-19
- 任务：HOTFIX-20260819-05
- 影响范围：Publisher Worker、官网 Render Adapter、企业名称公共策略
- 延续决策：ADR-0037、ADR-0041、ADR-0043、ADR-0049

## 已核验事实

生产日志中的失败任务属于“众人搬家-官网”，在 Publisher 调用官网发布接口前被
`OTHER_COMPANY_NAME_FORBIDDEN` 阻断；没有进入列举网外部请求。错误信息固定声称只允许
“广州志远搬家服务有限公司”。

ADR-0049 已使生文、质检和确定性风险扫描按当前 tenant/workspace 的已发布品牌档案识别企业名称，
但官网 Render Adapter 仍使用历史硬编码名称。结果是众人企业内容即使已通过当前租户质检，仍会在
发布前被另一个企业的规则拒绝。

## 决策

1. Publisher 领取任务时，按任务 tenant 和内容包 workspace 联合读取该工作区唯一的已发布品牌档案。
2. 使用公共策略从品牌档案的定位和 CTA 中提取完整法定企业名称，并把名称边界显式传给官网 Render
   Adapter；Render Adapter 不再保留任何默认企业名称。
3. 当前企业的完整法定名称允许出现；其他企业、品牌和指定企业信息平台名称继续阻断。
4. 当前工作区没有已发布品牌档案，或品牌档案未声明完整法定名称时，规则保持失败关闭：任何可识别
   企业名称都不得发布。
5. 名称只按完整、精确的法定名称匹配，不把“广东”和“广州”等不同名称视为同一企业，不做模糊放行。
6. 不降低冻结质量门槛，不伪造或重算模型质量结论，不自动修改或重投旧任务。

## 安全与兼容边界

- 查询同时约束 tenant、workspace 和 `status='published'`，不允许跨企业或跨工作区回退。
- 官网 Render 输入契约升级为 `official-site-render-rules@1.2.0`，企业名称边界为必填字段；空数组表示
  当前企业未声明法定名称，而不是恢复历史默认值。
- 无数据库迁移和公开 HTTP API 变化。
- 已失败任务部署后不会自动恢复；应核对内容中的法定名称与当前已发布品牌档案一致，再显式普通重试。

## 验收

- 众人工作区使用自身完整法定名称时，官网 Render 校验通过。
- 同一内容改为志远企业名称时，被 `OTHER_COMPANY_NAME_FORBIDDEN` 阻断。
- 缺少法定名称声明时保持失败关闭。
- Publisher 数据库集成测试证明 claim 取得当前 tenant/workspace 的名称，且既有发布与对账用例全部通过。
