# ADR-0074：抖音图文视觉与文案质量增强

- 状态：已批准实施
- 日期：2026-08-27
- 任务：T159
- 影响范围：`douyin` Content Writer、语义质量门禁、媒体规划与图文卡片渲染
- 前置决策：ADR-0014、ADR-0030、ADR-0073

## 背景

T158 已跑通抖音图文生成和真实发布，但首个验收作品主要把长文切成固定文字卡：页面之间信息密度
和叙事推进不足，图片缺少与单页主题对应的场景，发布说明也容易重复卡片内容。仅替换写作模型或让
视觉模型直接生成整张带中文字的海报，不能稳定解决错字、无证据画面和跨页重复问题。

## 决策

1. 新生成的抖音图文目标收敛为 6–9 张：封面、正文和总结顺序不变。旧的 5–10 张内容继续兼容
   读取、渲染和导出，不自动重写或重新评估。
2. 文案必须形成问题钩子、适用场景、判断标准、操作步骤或清单、风险或不适用边界和总结。每页只
   讲一个判断或动作；标题、正文和发布说明使用显式长度范围，禁止长文拆页、通用模板标题和跨页
   近重复。
3. 以上要求由 Content Writer 平台提示和服务端确定性语义门禁共同执行。不通过时沿用当前质量引导
   重写；服务端不得静默改写模型正文，也不得伪造质量通过。
4. 媒体规划器只从当前不可变卡片中选择 3–5 页生成背景，必须包含封面、不得包含总结。每个背景
   必须直接表现该页动作或判断，且不同页场景不得重复。
5. 背景使用现有 Cloudflare 图像 Provider 生成 3:4 匿名编辑插画，并在叠字前执行现有视觉模型门禁：
   相关性、安全、无文字、无品牌、无联系方式、无 Logo/水印和不得伪装企业真实证据。模型不得
   绘制证书、榜单、价格、二维码或可识别企业场所。
6. 中文标题、正文、页码和 AI 标识始终由服务端确定性 SVG/Sharp 渲染。视觉模型只产出无字背景，
   因而不能把模型画出的文字当作发布文案，也不能由画面新增事实。
7. 封面、插画正文、重点判断、清单和总结使用不同的受控版式。服务端在渲染前检查文字溢出；不得
   截断、隐藏或缩小到不可读来换取成功。
8. 任一背景生成或视觉质检失败时，只将该页回退到确定性编辑模板；规划失败则整组使用编辑模板。
   降级必须记录 Provider 错误和 `fallback` 状态，但不改变文章质量报告，也不阻断已通过内容。
9. 本次不新增数据库表、公开接口或生产配置。沿用现有 DeepSeek、Cloudflare、对象存储和媒体关系；
   不自动处理旧内容、旧报告、旧媒体运行和旧发布任务。

## 维护补充（HOTFIX-20260827-02）

真实发布回归显示，`fast` 首稿会跳过 Content Writer 语义不足项，导致 58 字说明在后续模型质检通过后
进入发布；卡片有完整篇幅并不能弥补公开作品说明过短。维护修正如下：

1. 抖音 `description` 是独立发布主文案，不再作为摘要字段使用；新范围为 420–900 字、5–8 个自然段。
2. 第一段固定完成主题与现实痛点，后续按解决方案、费用或服务边界、防护或责任、预约或工期、至少
   3 条编号实操建议和行动结论推进。主文案不得直接复制摘要、正文块或卡片。
3. 已发布品牌资料存在本企业法定名称时，至少在第二或第三段自然出现 1 次，全文最多 2 次；其他
   具名企业和无证据服务、案例、资质、报价或榜单继续阻断。
4. 抖音专用语义门禁对 `fast`、`balanced` 和 `quality` 首稿一律执行；`fast` 不再跳过说明长度、结构
   和叙事问题。失败仍由模型按报告完整重写，服务端不改正文也不伪造质量通过。
5. 旧内容、旧质量报告、旧素材和旧发布任务不自动重评；无数据库、公开 API 或生产配置变化。

## 维护补充（HOTFIX-20260828-01）

人工修改和其他非 Content Writer 入口原先只经过通用发布前质检，未复用上述抖音叙事门禁；浏览器实际
填写的是 `description`、换行和全部 `#topics`，原校验却只限制 `description`。维护修正如下：

1. 标题、主文案结构、话题、卡片、当前企业名称位置与频次统一由共享确定性策略计算；Content Writer
   与发布前 Quality Worker 使用同一结果，人工修改不能绕过生成门禁。
2. `description`、换行和全部 `#topics` 的实际创作者中心输入合计不得超过 1000 字。生成门禁、发布前
   质检、Render 最终安全校验和 Browser Worker 使用同一拼接函数与上限。
3. 旧 `script_package` 不适用图文叙事门禁，继续按 ADR-0073 兼容读取和导出。旧图文内容、旧质量报告
   和旧任务不自动重评；已排期旧任务只有在实际输入超过平台技术上限时才会于最终发布前失败关闭。
4. 本维护不降低事实、品牌、资质、图片或平台冻结门槛，不由服务端改写正文或伪造模型结论；无数据库、
   公开 API 或生产配置变化。

## 取舍

- 每组新增一次视觉规划及最多 5 次背景生成和 5 次视觉检查，媒体阶段成本与时延上升；调用保持有界
  且顺序执行，避免同一账号日批瞬时并发放大。
- 确定性模板仍是可发布降级，不承诺每组都使用生成背景；诊断必须能区分规划降级、生成降级和视觉
  质检降级。
- 本期不接入参考作品自动抓取、风格克隆、模型直接排版、视频合成、配音或自动选曲。

## 验收

1. 新内容不满足 6–9 张、单页长度、完整叙事、说明长度或跨页去重时不能通过语义门禁。
2. 视觉规划只选择现有卡片，必须含封面、不含总结、数量为 3–5，非法输出最多修复一次后降级。
3. 生成背景通过视觉门禁后才可与服务端文字合成；输出固定为 1080×1440 JPEG，并记录卡片版式、
   背景来源和视觉检查结果。
4. 所有模板与生成背景版式均不截断文字；图片失败不降低文章冻结质量门槛，也不伪造模型或远端状态。
5. 单元测试、类型检查、格式、构建和自审通过；真实发布和生产部署仍需用户单独授权。
