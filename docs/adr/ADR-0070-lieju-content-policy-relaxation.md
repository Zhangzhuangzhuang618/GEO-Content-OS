# ADR-0070：列举网平台内容门禁按官方口径收敛

- 状态：已批准实施
- 日期：2026-08-22
- 任务：HOTFIX-20260822-06
- 影响范围：列举网生文、质量检查、重写、发布前校验和自动化页面说明
- 修正决策：ADR-0037、ADR-0041、ADR-0048、ADR-0056、ADR-0068

## 已核验事实

业务方已与列举网官方确认：列举网不禁止正文出现其他网址，对品牌、事实和资质也没有额外的
平台级一刀切禁令。现有系统仍把网址、`权威` 和 `国家级` 作为列举网字面硬阻断，并在生文、
质量检查、定向重写和发布前渲染多层重复执行。该规则会误伤官方核验链接和有证据支持的资质说明，
属于系统自加限制，不是列举网当前明确要求。

## 决策

1. 列举网标题和正文允许与内容相关的 HTTP(S) 网址、`www.` 地址和裸域名，包括官方核验链接。
   `contact_in_content_forbidden` 对列举网只表示具体电话号码、微信 ID 和 QQ ID；中性的页面联系
   引导继续允许。
2. `权威` 和 `国家级` 不再作为列举网发布层的无条件字面禁词。明确排名、极限词、结果保证和
   绝对化宣传仍按既有确定性规则阻断。
3. 品牌、事实和资质不是列举网平台默认禁区。本企业名称、与已发布品牌资料一致的第一方事实以及
   由当前企业授权证据和 `citation_map` 直接支持的资质声明可以通过。
4. 平台未禁止不等于内容可以失真。跨租户企业名称、冒用其他企业、与品牌资料冲突的事实、无证据
   资质、虚假价格、竞品贬损、虚构案例和结果保证继续执行既有系统级 BLOCK；GEO、事实、品牌、
   可读与安全、问题覆盖和平台适配分数门槛不变。
5. Content Writer、Quality Checker 语义约束、AI Worker 确定性扫描、定向修复和 Lieju Render
   统一使用上述边界。定向修复不得再仅因网址删除域名，但仍要删除命中的电话、微信或 QQ 具体值。

## 兼容性与恢复边界

- 无数据库迁移、公开 API 或状态机变更；既有 `contact_in_content_forbidden=true` 的含义按本 ADR
  收敛为电话、微信和 QQ 具体值。
- 旧内容、旧质量报告、旧批次和旧发布尝试不自动重评。因网址或旧字面禁词停在内容处理阶段的任务
  需要显式重新质检或发起新尝试；已经创建且只在 Render 被网址阻断的发布任务可在部署后普通重试。
- 不由服务端删除模型真实问题、修改质量分或伪造通过结论。

## 验收

- `https://...`、`www.gsxt.gov.cn` 和 `ysfw.mot.gov.cn` 不再触发列举网联系方式问题，发布前
  Render 同样允许。
- 电话、微信 ID 和 QQ ID 继续在生成后、确定性质检和 Render 层阻断。
- `权威`、`国家级` 不再单独触发列举网字面禁词；无证据的资质、事实和绝对化宣传仍由原有系统
  门禁阻断。
- 百家号等其他平台的外链规则不受影响。
- Contracts、Skills、AI Worker、Lieju Render、Web、类型检查和全量回归通过。
