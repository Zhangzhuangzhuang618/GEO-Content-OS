# ADR-0043：品牌质检语义重判诊断

- 状态：已批准实施
- 日期：2026-08-17
- 任务：HOTFIX-20260817-10
- 影响范围：所有平台共用的 Quality Checker 与 AI Worker
- 前置决策：ADR-0027、ADR-0040、ADR-0041、ADR-0042

## 背景

列举网人工重新质检时，模型连续两次返回不可验证的 `brand.other_company_name`。共享质检虽然正确拒绝
了无依据问题，但只向第二次模型重判提供通用错误“指定位置没有禁止名称”，没有说明究竟是自家公司
被误判、行业泛称被误判、没有引用名称，还是名称与位置不一致。第二次调用无法针对首次错误纠正，
最终进入 `manual_required`。

## 决策

1. 品牌问题断言继续要求 `brand/BLOCK`、精确正文位置、消息引用具体禁止名称，且该名称真实存在于
   声明位置；不满足任一条件仍返回 `SKILL_OUTPUT_INVALID`。
2. 拒绝信息增加一个脱敏原因码，只记录规则、分类、严重级别、位置和以下原因之一：分类错误、严重
   级别错误、缺少位置、位置无法解析、未引用准确名称、只引用允许的自家公司或行业泛称、引用名称
   不在声明位置。不得记录模型原始消息、正文、凭据或其他自由文本。
3. 既有的一次语义重判接收该原因码，并按原因明确要求模型删除无依据问题或改为准确名称和位置；
   模型仍必须重新返回完整质量结果，服务端不删除问题、不计算替代分数或决策。
4. 第二次结果仍无效时继续失败关闭并进入人工处理，不增加第三次调用，不恢复队列级重复重试。

## 不变项

- 冻结质量分、BLOCK、告警阈值、最多三次内容重写和真实发布门槛保持不变。
- 确定性第三方名称扫描继续执行，真实第三方企业或品牌名称仍然阻断。
- 旧内容版本、旧质量报告和旧运行不重新评估；无需数据库迁移、API 或 Web 变更。

## 验收

- 自家公司与允许行业泛称的错误品牌问题返回明确原因，并把该原因传给第二次完整模型重判。
- 未引用名称、错误位置和错误分类分别返回稳定、脱敏的原因码。
- 准确引用正文真实第三方名称的问题仍正常形成 BLOCK。
- Skills、AI Worker、类型检查和全量回归通过。
