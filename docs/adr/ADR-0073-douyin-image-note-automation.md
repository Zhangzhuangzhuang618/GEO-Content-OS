# ADR-0073：抖音图文作品生成与托管浏览器发布

- 状态：已批准实施
- 日期：2026-08-26
- 任务：T158
- 影响范围：`douyin` 内容生成、质量门禁、图文卡片渲染、发布与状态核验
- 前置决策：ADR-0014、ADR-0028、ADR-0030、ADR-0037

## 背景

现有抖音能力只生成 60–90 秒口播脚本、分镜、字幕和话题，并导出脚本包，不生成成片，也不连接
抖音创作者中心。抖音创作者中心已经提供独立“发布图文”入口，支持一次上传多张 JPG、JPEG、PNG
或 WebP 图片；公开图文作品以图片组轮播展示，不等同于 MP4 视频。

本期目标是补齐与参考作品相同类别的“多页知识图文卡片”，不是建设通用视频剪辑、配音或音乐合成
平台。

## 决策

1. 新生成的抖音变体默认使用 `image_note`，输出标题、说明、话题和 5–10 张结构化卡片；旧的
   `script_package` 内容和导出仍可读取，不自动重写或重新评估旧内容。
2. 图文卡片必须由确定性模板渲染为 1080×1440 JPEG：首张封面、3–8 张正文卡和一张总结卡。
   模型只负责结构化文字，不直接在图片中绘字；服务端负责换行、字号、留白、页码和品牌色，任何
   文本溢出都必须阻断该媒体任务。
3. 卡片文字来自当前不可变内容版本。涉及事实、品牌、资质、价格或统计的表述继续受当前引用和冻结
   质量门禁约束；卡片渲染不得添加正文中不存在的结论。服务端不得伪造模型质量结论。
4. 抖音图文素材使用既有 `media_assets`、`content_media_runs` 和 `content_media_assets` 保存，
   首图角色为 `cover`，其余为 `body`，位置和内容哈希保持幂等。此类确定性文字卡片使用独立
   `douyin-note-card@1` 质量记录，不套用“生成场景图不得含文字”的视觉模型规则。
5. 抖音接入既有浏览器平台日批：独立生文、冻结质检、最多三次按当前报告重写、图文卡片渲染、
   自动排期和托管浏览器发布。候选耗尽时合格多少排期多少，剩余数量进入需要处理；不影响其他平台。
6. 新增独立 `workers/douyin-browser`。用户通过抖音创作者中心二维码建立会话；storage state 使用
   现有凭证信封加密，明文 Profile 只存在受限 `tmpfs`，同一账号并发固定为 1。
7. Browser Worker 固定选择“发布图文”，按图片位置上传完整卡片组，填写标题、说明和话题，并如实
   设置可用的 AI 内容声明。不得自动声明原创、选择商业推广、购买流量或绕过验证码、风控和实名校验。
8. 点击发布前保存不可变尝试和内容指纹。提交后从内容管理页按账号、精确标题、时间窗口和页面可用时的素材指纹对账；
   唯一匹配才进入 `processing | published | failed`，多条匹配或页面不可验证进入人工处理。只有远端
   已发布并取得作品地址时，系统才完成发布任务。
9. 浏览器上传、提交和对账失败不改变文章质量结论。未知态先核验再重试，不重复上传或重复发布。
10. 本期不自动选择背景音乐。若创作者中心网页端没有稳定、可审计的音乐接口，作品按无音乐图文发布；
    音乐和 MP4 合成需后续独立决策。

## 数据与接口

- 扩展抖音 Render/Delivery 契约，新增 `image_note` 载荷及确定性图片顺序。
- 扩展浏览器平台自动化表约束和发布任务来源，允许 `douyin`。
- 新增 `douyin_browser_sessions`、`douyin_browser_publications`、
  `douyin_browser_artifacts`。
- 新增抖音登录状态、扫码登录和重新认证接口，以及 `douyin.publication.reconcile_requested.v1`。
- 新增 3 个公开接口；在 ADR-0071 的 166 个端点基线上增至 169 个。
- 抖音账号默认使用 Browser Gateway；保留原脚本包导出作为降级和旧内容兼容能力。

## 明确不做

1. 不生成、拼接或转码 MP4，不做 TTS、配音、自动选曲和音乐版权管理。
2. 不把浏览器提交成功伪装成远端发布成功。
3. 不降低文章质量、事实、品牌、安全或平台适配门槛。
4. 不自动绕过登录、验证码、实名认证、账号风控或平台审核。
5. 不自动重新处理旧抖音内容、旧质量报告、旧素材或旧发布任务。

## 验收

- 新抖音内容稳定生成 5–10 张卡片，图片为 1080×1440 JPEG，顺序、哈希和版式可复现。
- 超长文字、缺失封面/总结、未知品牌、无证据高风险声明和素材缺失均失败关闭。
- 旧 `script_package` 仍能按旧格式导出；新 `image_note` 导出包含图片清单、文案和元数据。
- 图文账号登录、进程重启恢复、串行发布、未知态核验和重复匹配测试通过。
- 自动测试只访问本地仿真页面；真实抖音发布必须由用户另行确认。
- Contracts、迁移、API、AI Worker、Publisher、Browser Worker、Web、OpenAPI、SDK、构建和自审通过。
