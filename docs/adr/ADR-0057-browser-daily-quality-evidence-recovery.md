# ADR-0057：浏览器平台日批证照证据与质检恢复

- 状态：已批准实施
- 日期：2026-08-20
- 任务：HOTFIX-20260820-05
- 影响范围：搜狐号与列举网日批证据检索、Content Writer、Quality Checker、质量重写、PUB-01
- 延续决策：ADR-0037、ADR-0040、ADR-0041、ADR-0043、ADR-0049、ADR-0053、ADR-0054

## 已核验事实

2026-08-20 的生产记录中，列举网 20 个日批候选有 9 个进入人工处理：6 个为 Quality Checker
返回不可验证的企业名称问题，1 个在质量报告引导重写时耗尽工具调用轮次，2 个被“资质声明缺少
证据”硬规则阻断。后两篇正文确实声明了营业执照、道路运输证或道路运输经营许可证；生产企业资料
已上传相应证明，因此不能把问题归类为资质规则误报，也不能通过删除硬规则解决。

逐候选检索此前只按文章主题选取最多 5 个片段。证照即使已经上传、解析和授权，也可能因与文章
主题的相似度较低而未进入该候选的不可变 Writer 输入；重写链路又曾从当前已采用引用反向重建输入，
导致原输入中未被首稿采用的证据永久丢失。结构化证照中的“证照名称”也不等于正文完整声明句，
普通字面证据匹配无法可靠判断一项或多项资质是否均有证明。

## 决策

1. 搜狐号和列举网日批在既有最多 5 个片段、每份资料最多 2 个片段的边界内，先预留最多 3 个
   结构化证照片段，再用主题检索结果补满。候选证照必须属于当前 tenant、workspace，并属于当前
   project 或该工作区的通用资料；状态有效、可信度非不可信、仍在有效期内，并已明确允许正文使用
   和公开展示。最多 3 个证照的限制同时覆盖证照专用检索与主题检索，并优先从不同证照来源各取
   1 个片段，避免同一证照的正反面挤掉另一项许可证；主题检索不得把未授权的结构化证照带入 Writer
   输入。
2. 证照持证主体必须精确匹配当前工作区已发布品牌档案中的法定企业名称。不得模糊匹配、跨企业
   回退，亦不得使用另一个租户或企业的证照支持当前文章。
3. Content Writer 只有在 `citation_map` 把资质声明关联到当前输入中的结构化企业证照，且声明中
   每一项证照名称均能匹配、持证主体精确一致时，才允许保留该声明；否则由模型重写删除或补齐引用。
   每个候选将当时可用的授权证照 source ID 冻结进 Writer 输入；Quality Checker 还要从引用来源
   重新核验当前项目范围、授权、公开确认、状态和有效期，再使用同一逐项规则决定是否继续输出
   BLOCK。不能仅凭引用文本自称“企业证照”解除阻断，服务端也不得静默改文或伪造通过结论。
4. 质量报告引导重写必须从原始 `content.package.generation_requested.v1` 事件加载冻结的 Writer 输入，
   保留原始 citations、策略、平台规则和适用锁定块。旧候选不重新检索，重写也不得借用最新资料。
5. 质量引导重写不开放 `get_strategy_version` 或 `get_platform_rules` 工具；所需策略和规则已冻结在
   Writer 输入中，避免模型在修正文稿时重复调用工具直至耗尽轮次。
6. Quality Checker 的一次语义恢复继续由模型返回完整质量结论，但使用独立修复任务，明确禁止把
   被服务端拒绝的 few-shot 或旧任务示例问题原样复制。“某公司”“某搬家公司”“某银行”“某金融
   机构”等明确匿名称谓继续放行；企业名称问题必须引用正文中可识别的真实具名企业或受支持的具名
   平台，不能把普通短语误报为企业名。具名第三方企业仍阻断，修复任务继续携带本次输入的标题长度、
   有效内容位置、高风险事实位置和列举网联系方式规则。
7. PUB-01 只显示可执行的用户提示，不直接展示内部错误码、模型英文消息或语义校验 JSON。原始诊断
   继续保存在服务端日志和审计数据中，不改变运维排障能力。

## 兼容性与恢复边界

- 不降低 GEO、事实、品牌、可读性与安全、问题覆盖或平台适配门槛；真实无证据资质声明仍然 BLOCK。
- 不新增公开 API、数据库表、迁移、队列或模型调用轮次上限；资质绑定失败复用 Content Writer
  既有的确定性修正轮次。
- 旧批次、旧候选、旧 Writer 输入和旧质量报告不会自动重新检索或重新评估。若旧候选的原始输入
  已包含对应证照，可显式重新质检进入原证据重写；原输入没有证照时必须发起新的日批尝试。
- 仅上传文件不等于可用于文章。未确认正文使用与公开展示、主体不一致、失效或不可信的证明不会被
  选入证据，也不能解除资质阻断。

## 验收

- 同一项目的搜狐号和列举网新候选均能在 5 个片段上限内优先取得当前企业授权证照。
- 营业执照、道路运输证和道路运输经营许可证的组合声明必须逐项具备当前企业证照；缺一项或主体
  属于另一企业时继续阻断。
- 质量重写复用原始冻结证据且不调用工具，旧报告问题不会因上下文重建而丢失。
- 匿名“某银行”不会被当作具名第三方；真实具名第三方继续阻断。
- PUB-01 不显示内部错误码或 JSON，仍提供重新质检和全文处理入口。
- Contracts、Skills、AI Worker、API 集成、Web 构建与 PUB-01 回归测试通过。
