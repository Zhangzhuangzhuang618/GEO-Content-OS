# ADR-0019：平台账号完整生命周期

## 状态

已接受，作为冻结文档中 PUB-01 平台账号管理的可执行修正。

## 问题

原 PUB-01 仅支持连接、刷新授权、能力测试和停用。账号名称、时区、交付模式及凭证无法更新；停用账号无法恢复；已注销账号无法从可用列表移除，不能满足账号密码或令牌变更、误停用和账号注销场景。

## 决策

- 新增 `PATCH /platform-accounts/{id}`，修改账号名称、时区、交付模式，并可原子替换加密凭证。凭证永不回显。
- 新增 `POST /platform-accounts/{id}/restore`，重新探测已有凭证及平台能力后恢复停用账号。
- 新增 `DELETE /platform-accounts/{id}`，执行可审计的软删除；已删除账号不再出现在列表或发布任务账号选择中。
- 停用账号允许编辑资料和轮换凭证，但编辑不会自动启用，必须显式恢复。
- 停用或删除前检查 `scheduled`、`publishing`、`cancel_requested` 发布任务；存在活动任务时拒绝操作，要求先处理任务。
- 平台与工作区保持不可变，避免破坏既有内容变体、权限范围和发布记录。
- 所有写操作继续要求 CSRF、`If-Match` 乐观锁、租户与工作区授权，并写入不含明文凭证的审计事件。

## 影响

公开业务 API 由 122 个增加至 125 个。数据库已有 `platform_accounts.deleted_at`、`version` 和审计表，不新增迁移。
