# ADR-0016：知识库 URL 表格批量导入

## 状态

Accepted — 2026-07-20

## 背景

冻结版 KNOW-02 只支持一次登记一个 URL。实际资料整理经常以 XLSX 或 CSV 保存 URL
清单，逐条复制会产生漏项、重复和不可见失败。冻结文档没有批量写入契约，因此该能力必须以
显式 ADR 扩展，不能静默改变 `POST /sources`。

## 决策

- 新增 `POST /sources/batch-url-preview`，仅解析最多 10 MiB 的 XLSX/UTF-8 CSV，返回工作表、
  行号、URL、可选标题和逐行校验结果；单批最多 500 条非空 URL。
- 预检默认读取 D 列，优先选择名为“详细URL列表”的工作表，并自动识别 URL/网址/链接表头
  后的首行；用户可以修改工作表、URL 列、标题列和起始行。
- 预检只做文件格式、HTTP(S) URL 和文件内重复校验，不抓取网页、不写数据库。
- 用户确认后，Web 端限速顺序调用既有 `POST /sources`；遇到 429 时按 `Retry-After` 自动等待并
  重试当前行。每条 URL 继续独立执行 CSRF、权限、SSRF、内容与 URL 去重、事务、审计、
  Outbox 和 Knowledge Worker 流程。
- 每行独立显示成功、跳过或失败；部分失败不回滚已成功资料，失败项可单独重试。
- 不新增数据库表或迁移，不修改冻结 DOCX。

## 后果

- 可执行 API 总数从 121 增至 122；契约、OpenAPI、SDK、`PROJECT_CONTEXT.md` 和测试同步更新。
- 批量提交依赖浏览器页面保持打开；这是 MVP 的明确边界。后续只有在需要离线续跑时，才引入
  持久化批处理任务。
- URL 是否可访问及是否与已有资料内容重复，仍以单条入库接口的实际抓取结果为准，预检不会
  给出虚假的“可入库”保证。
