# ADR-0018：知识库 URL 快照与真实解析状态

## 状态

Accepted — 2026-07-20

## 背景

URL 登记阶段已完成安全抓取并计算内容哈希，但历史实现只保存 URL，Knowledge Worker 随后再次
抓取网页并要求内容逐字节一致。带时间戳、随机令牌或动态推荐内容的网页因此被误判为内容变化。
同时，资料列表未读取工作空间共享资料的详情，把已完成任务显示为“尚未完成”。

## 决策

- URL 登记成功后，将本次安全抓取的响应正文作为不可变解析快照写入私有对象存储；资料的 `uri`
  继续保存来源 URL，事件同时携带 `object_key` 和 `source_url`。
- Knowledge Worker 优先读取 URL 快照，并使用 `source_url` 生成可追溯定位信息；仅为历史事件保留
  无快照时的二次抓取兼容路径。
- 重新索引优先复用现有快照。历史失败 URL 没有快照时，先安全抓取并保存；只有资料尚无分块且
  处于失败状态时，才允许采用新的内容哈希，防止覆盖已被引用的成功资料。
- 提供内部维护命令批量为失败 URL 建立快照并创建重新索引任务。无效页面、重复正文和无法解析
  的内容继续保持失败，不伪造成功状态。
- 资料列表以当前项目作为权限上下文读取工作空间共享资料详情，展示真实完成时间和失败状态，并
  允许进入详情页。
- 不新增公开 API、数据库表、迁移或错误码；冻结 DOCX 保持只读。

HOTFIX-20260819-08：建行龙集采详情采用 `#/content?pId=...&id=...` 客户端路由，普通 HTTP
抓取只能得到无正文的 SPA 外壳。安全抓取器仅对
`https://ibuy.ccb.com/cms/index.html#/content` 的严格数字参数路由启用受限解析：通过站点公开栏目
索引确定年份，再读取对应公开详情 JSON，生成确定性的 HTML 快照；资料 URL 和引用定位保留完整
语义路由。内部请求继续逐次执行 DNS、SSRF、端口、重定向、响应大小、MIME 和总超时校验，不引入
通用浏览器渲染。已丢失 fragment 的历史失败记录无法自动推断目标详情，不自动重评，须使用完整
链接重新导入。

## 后果

- 动态网页不会因为登记与 Worker 两次抓取之间的非实质变化而误判失败。
- 新增 URL 会占用对象存储空间，但获得稳定、可审计、可复现的解析输入。
- 历史失败资料可安全重试；目标网站拒绝服务器抓取、返回错误页或没有可提取正文时仍会失败。
