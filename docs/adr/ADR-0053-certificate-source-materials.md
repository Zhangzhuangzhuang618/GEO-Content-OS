# ADR-0053：企业证照作为结构化知识资料与受控文章素材

- 状态：已批准实施
- 日期：2026-08-19
- 任务：T155
- 修订：HOTFIX-20260819-06
- 影响范围：资料导入、Knowledge Worker、内容配图、Publisher、官网 Render Adapter
- 延续决策：ADR-0014、ADR-0030、ADR-0031、ADR-0034、ADR-0035

## 已核验事实

现有“导入资料”只允许 PDF、DOCX、TXT 和 URL。后端能够识别图片，但生产配置不提供可用 OCR，
因此不能把 OCR 结果伪装成已核验的证照事实。证照原图可能含有需要公开核验的证照编号、持证主体、
发证机关，也可能含有与业务无关的个人信息；系统不能仅凭文件类型决定公开展示。

文章媒体与不可变内容版本独立关联。官网可以通过随文上传获得持久地址，百家号和搜狐号可以上传私有
素材；列举网官方 API 的图片受公网地址和平台字段限制，当前无可靠的私有证照发布链路。

## 决策

1. “导入资料”支持 PNG、JPEG、WebP 企业证照。上传时必须人工填写证照名称、证照编号、持证主体
   和发证机关，可选填写 HTTPS 官方核验链接，并继续使用资料有效期字段。
2. 证照图片必须通过扩展名、MIME、内容签名、解码、尺寸和大小校验；允许范围为至少
   768×512、每边不超过 8192 像素、总像素不超过 5000 万且不超过 10 MB。该独立输入门槛用于
   接受常见高分辨率扫描件，不改变普通生成图片的 4096 像素门槛；原图仍保存在私有对象存储。
3. Knowledge Worker 不调用 OCR，也不从图片像素推断事实。它只把用户明确确认的结构化字段生成
   可检索文本和可追溯引用；服务端不得伪造 OCR、脱敏或模型质量结论。
4. 是否允许随文章展示必须单独授权。授权者同时确认拥有公开权利，且原图不含无关个人证件号、
   银行卡或私人联系方式。未授权、不可信、失效、已删除或未被当前内容实际引用的证照不得进入文章。
5. 进入文章前再次按 tenant、workspace、project、当前内容版本引用和当前已发布品牌档案校验；
   持证主体必须精确匹配当前企业法定名称，不做跨企业回退或模糊匹配。
6. 发布使用重新编码的 1200×800 JPEG 副本，保留完整证照画面、不裁切主体并移除文件元数据；
   原图不公开。官网明确标注“企业证照，请按编号或官方渠道核验”，不得标为 AI 图片。
7. 官网、百家号和搜狐号可使用满足上述条件的证照副本。列举网首版不自动附带证照图片。
8. 证照副本处理或存储失败时记录脱敏诊断并无图继续，不能阻断已经通过冻结质量门禁的文章。

## 安全与兼容边界

- 证照元数据采用精确的 `source-certificate@1` 结构，并由数据库约束字段集合、长度、布尔授权关系和
  HTTPS 核验链接。
- 文章引用授权不会改变 `content_versions.content_json`、旧质量报告或既有引用；仅对新配图运行生效。
- 原有 PDF、DOCX、TXT、URL 和历史图片资料保持原解析路径，不自动转换或重新入库。
- 本决策不降低 GEO、事实、品牌、可读性与安全、问题覆盖或平台适配门槛。

## 验收

- 证照图片可以上传、私有保存、异步入库、检索并在详情页查看结构化核验字段。
- 伪造格式、损坏图片、越界尺寸、非 HTTPS 核验链接和缺少公开确认的展示授权均被拒绝。
- 证照入库不调用 OCR；原图哈希与发布前读取内容不一致时拒绝生成副本。
- 只有当前内容真实引用、当前企业名称匹配且明确授权的证照才会成为文章媒体。
- 官网输出不带“AI示意图”；列举网不附带证照；媒体失败按无图降级。
- Contracts、迁移、OpenAPI、API、Web、Knowledge Worker、AI Worker、Publisher 和平台 Adapter
  的测试与构建通过。
