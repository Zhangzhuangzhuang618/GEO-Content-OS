# ADR-0020：平台发布后台快捷入口

## 状态

已接受，作为冻结文档中 PUB-01、PUB-02 人工发布流程的可执行修正。

## 问题

确定性导出和人工发布模式生成内容后，用户必须自行寻找各平台创作后台，平台账号管理和发布任务之间缺少直接交付入口；企业官网也无法保存自身 CMS 发布页。

## 决策

- `platform_accounts` 增加可空 `publishing_url`，仅允许 HTTP/HTTPS，最大 2048 字符。
- 创建和编辑平台账号时可配置发布后台地址；企业官网使用该地址进入自有 CMS。
- 百家号、头条号、知乎、小红书、微信公众号和抖音在未配置自定义地址时使用系统默认创作入口。
- PUB-01 账号列表、PUB-02 账号选择和发布任务列表提供“发布后台”入口，使用新标签页并设置 `noopener noreferrer`。
- 入口只负责导航，不读取平台登录信息、不绕过登录、验证码、扫码或二次验证，也不伪造发布成功状态。
- 停用账号不在 PUB-01 提供快捷发布入口；默认地址失效时可通过编辑账号覆盖。

## 影响

数据库迁移增至 0035，表数仍为 57，公开 API 数仍为 125。平台账号 DTO、OpenAPI、SDK和审计快照同步包含 `publishing_url`。
