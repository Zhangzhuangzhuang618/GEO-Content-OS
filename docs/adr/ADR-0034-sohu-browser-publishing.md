# ADR-0034：搜狐号内容生成与托管浏览器发布

- 状态：已批准实施
- 日期：2026-08-14
- 任务：T150
- 影响范围：`sohu` 普通内容生成、质检、审核、排期和浏览器发布
- 前置决策：ADR-0014、ADR-0028、ADR-0030

## 决策

搜狐号作为第八个平台接入既有内容主链路，不新增日批或同源派生策略。用户选择搜狐号后，系统生成独立变体，执行现有冻结质量门禁，经审核和排期后由独立 `workers/sohu-browser` 进程发布。

平台规则固定标题 5–72 字、摘要不超过 120 字、正文至少 5 个非标题/媒体内容段。发布载荷固定 `ai_generated=true`、`original=false`；浏览器必须选择“包含AI创作内容”，不得声明原创。

账号通过微信扫码登录，不保存账号密码。storage state 使用既有凭证信封加密；明文 Profile 只存在受限 `tmpfs`。验证码、风控、登录失效和页面签名变化均失败关闭，不绕过安全验证。

提交成功不等于发布成功。系统从搜狐号内容管理页持续对账 `processing | published | failed | unknown`；只有远端为 `published` 才完成发布任务。未知状态禁止直接重复点击，必须先按账号、标题和提交时间核验；多条匹配进入人工处理。人工确认已发布或未发布的入口同时支持搜狐号。

## 数据与接口

- 新增 `sohu_browser_sessions`、`sohu_browser_publications`、`sohu_browser_artifacts`。
- 新增 `sohu.publication.reconcile_requested.v1`。
- 新增搜狐登录状态、扫码登录、重新认证 3 个公开端点；可执行端点总数从 147 增至 150。
- `platform_rule_versions` 新增已发布搜狐规则；平台枚举扩展为 8 个。

## 明确不做

1. 不新增搜狐日批、官网派生或自动跳过人工审核。
2. 不访问生产官网，不在自动测试中向真实搜狐号发布文章。
3. 不伪造平台成功状态或模型质量结论。
4. 不自动绕过验证码、实名认证或平台风控。

## 上线门禁

单元、契约、迁移、类型检查、本地搜狐页面仿真 E2E、未知态和重复匹配测试必须通过。首轮只允许单账号、串行、低频灰度；真实发布需另行明确授权。
