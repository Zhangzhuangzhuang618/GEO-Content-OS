# ADR-0084：广州11区账号独立轮换

日期：2026-09-12。状态：实现，本地验证。

## 决策

区域是账号内容设置的独立布尔开关，只用于官网、列举网和抖音日批，不增加第三种写作风格。默认关闭。

账号游标指向下一个区，日批插入时在同一事务内冻结当天地区数组，并按计划数量推进游标。账号、日期唯一计划供同日补篇重用；候选记录槽位，失败退休后补回同槽位。轮换不依赖模型尝试次数或发布结果。

地区只作用于派生选题及冻结编辑上下文，原关键词和企业法定资料不替换。抖音沿用原去重机制，启用时派生关键词含区名，未启用时原行为不变。质检要求标题带目标区，语义审查正文、FAQ及卡片。

## 一致性

数据库AFTER INSERT分配计划，避免ON CONFLICT空插入推进游标。内容设置快照先获取写锁，避免并发插入由共享锁升级导致死锁。计划不可更新，已绑定批次不可改绑。关闭暂停，再开启续接；不自动补旧日缺额。

## 取舍

固定广州11区轮换，不增加权重、自选区或额外排期体系。已有数量和时间不因开关改变。模型文字质量仍由原生成/改写/质检链路负责，不以区域开关保证每次首次生成成功。
