# 问天GEO连接器部署清单

> 适用范围：GEO Content OS侧；问天仍独立部署

## 上线前准备

1. 在问天管理端创建GEO连接器，记录连接器编号、一次性显示的服务端密钥和问天企业编号。
2. 确认问天具有公开HTTPS地址。生产环境不允许使用明文HTTP，也不允许地址携带账号、密码、路径、查询参数或片段。
3. 在GEO API部署环境中同时设置：
   - `WENTIAN_BASE_URL`
   - `WENTIAN_GEO_CONNECTOR_ID`
   - `WENTIAN_GEO_CONNECTOR_SECRET`
   - `WENTIAN_GEO_TENANT_ID`
4. 执行GEO迁移`0052_wentian_geo_connector.sql`，再部署API和Web。
5. 不要把连接器密钥写入浏览器环境、前端构建参数、日志、工单或仓库。

四项配置全部留空时，连接器关闭，GEO其他功能正常运行；只填写其中一部分时，页面显示“配置无效”且所有写操作失败关闭。

## 首次联通

1. GEO企业所有者或管理员打开“数据 → 问天信源探测”，明确选择工作区和项目。
2. 点击“申请连接”。
3. 问天Owner在问天管理端查看待处理申请，明确选择一个问天项目并批准。
4. 返回GEO点击“刷新状态”，确认显示“已连接”。
5. 选择一个AI可见度问题集并同步，确认问天生成不可变快照。
6. 点击“进入问天”，确认一次性票据只能消费一次、60秒后失效，并跳转到不含票据code的问天项目页。

## 故障与回滚

- 问天不可用：GEO显示暂时不可用，其他页面、任务和队列不得受影响。
- 密钥疑似泄露：先在问天轮换或吊销密钥，再更新GEO服务端配置；不需要清理浏览器。
- 需要停用：清空全部四项配置并重启GEO API。已有本地连接记录和问天历史实验保留。
- 需要断开项目：在GEO页面执行“断开连接”；此操作不删除问天项目、回答、证据或报告。

## 当前版本边界

`wentian-geo-connector@1`的T157首版包含绑定、状态刷新、一次性进入票据和问题集同步。Webhook事件回传按ADR-0071后置，不是本次上线依赖。
