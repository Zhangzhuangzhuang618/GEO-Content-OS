# HOTFIX-20260806-23 百家号精确发布按钮

## 真实页面证据

- 第二篇正式驱动已完成封面、正文和发布前校验，但等待平台发布接口 30 秒后返回 `PUBLISH_STATE_UNKNOWN`。
- 随后按精确标题检查“全部、已发布、待发布、未通过、已撤回、草稿”六个状态，均不存在目标文章，可以确认平台没有创建内容。
- 发布前截图显示页面底部按钮依次为“存草稿、预览、定时发布、发布”。
- 只读 DOM 诊断确认旧提交选择器依次匹配“定时发布”和“发布”，`.first()` 实际选中“定时发布”；因此没有发出 `/pcui/article/publish` 请求。

## 修复

- 发布按钮改用精确可访问名称，只匹配完整文本“发布”或“提交”。
- 不再使用会把“定时发布”纳入结果的包含文本选择器。
- 浏览器仿真在真正发布按钮前增加“定时发布”，确保驱动仍只触发精确发布按钮。

## 安全边界

- 不增加发布点击次数，不对未知态自动重试。
- 不放宽封面、AI 声明、质量、幂等或发布确认门禁。
- 未获得平台成功确认时仍按未知态停止并先做远端核验。

## 部署与验收

- 重新构建并部署 Baijiahao Browser Worker；无需数据库迁移。
- 单元测试和浏览器回归必须保持通过。
- 第二篇必须由正式驱动取得平台成功确认，并在内容列表按精确标题检索到，之后才能统一推送本批 Hotfix。
