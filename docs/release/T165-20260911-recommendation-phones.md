## 范围

官网、列举网、抖音的推荐公司新增可选 `service_phone`，复用既有大陆手机号、座机、400/800 格式验证。主公司电话只从当前租户/工作区企业资料 `official_site_service_phone` 读取，不在推荐配置重复维护；关联公司单独保存。账号默认风格、日批覆盖和已保存常规口吻不变。

生成候选解析企业资料时冻结主公司有效电话，关联公司电话随账号配置冻结。正文由服务器在对应公司介绍后添加独立联系段，抖音发布主文案在对应公司段内同步添加；不要求模型生成号码，不把电话混入服务引用。官网原有主公司 CTA 保留。人工编辑沿用当前版本电话快照，不回填最新配置。既有无电话快照仍兼容，不修改历史文章和排期。

生成质检与发布门禁仅排除正确位置、完全匹配冻结配置的联系段后运行原有电话检查；缺失、移用、未配置号码仍拒绝。列举网发布输入接收服务端风格快照，不向平台输出配置对象。常规风格保留原限制。

没有新增表或数据库迁移；更新 JSON 契约、OpenAPI、账号设置页面及共享校验。Web 构建并发限制为 1，避免共享生产 Docker VM 同时启动多个静态页面构建进程。
