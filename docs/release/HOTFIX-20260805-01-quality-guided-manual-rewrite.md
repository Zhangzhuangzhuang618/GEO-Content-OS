# HOTFIX-20260805-01 按质检报告人工重写

## 问题

质量报告页的“重新生成内容”复用了普通全新生成接口，只提交锁定段落和模型策略。服务端没有读取当前质量报告，AI Worker 因而看不到规则、位置、错误信息和修改建议；用户反复点击后可能重复生成同类不合格内容。

## 修复

- 质量报告页将入口明确为“按质检报告重写”，请求携带当前报告 ID，不再伪装成普通全新生成。
- API 只接受目标内容当前版本的最新质量报告；旧版本、旧报告、其他平台报告和已通过报告均不能驱动重写。
- API 从数据库读取当前全文和报告，将问题严重级别、规则、位置、错误信息、修改建议及自动化阻断规则组成可信重写快照。
- 生成事件增加受校验的重写快照；AI Worker 将原全文和报告诊断交给 Content Writer 做定向修改。
- 官网直接生成模式继续使用正文与 FAQ 分阶段链路，并在正文阶段接收报告诊断；百家号、头条号、知乎、小红书、微信公众号和抖音通过通用定向重写链路接收同一类诊断。
- 普通内容编辑器的“重新生成”仍表示全新生成；未绑定自动化策略的平台，重写完成后仍由用户发起质量检查。

## 冻结契约

- 未修改字数、结构、事实、品牌、合规、来源相似度或质量分数门槛。
- 服务端只传递已持久化的模型质检结论，不创建或篡改质量结论。
- 重写结果仍须经过原有机器质检和发布门禁。

## 验证

- AI Worker：16 个测试文件、82 项测试通过。
- 百家号质量报告重写数据库集成测试通过。
- 质量报告页 Playwright：8 项测试通过。
- Contracts、API、AI Worker、Web 类型检查通过；Web 生产构建通过。
