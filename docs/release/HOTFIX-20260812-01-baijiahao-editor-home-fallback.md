# HOTFIX-20260812-01 百家号首页回退进入图文编辑器

## 生产证据

- `日志 (5).txt` 显示发布任务在 `verify_editor` 阶段返回 `PAGE_SIGNATURE_CHANGED`，尚未填写标题、正文或点击发布。
- 同次诊断截图是包含“发布作品”“内容管理”“个人中心”的已登录百家号首页，不是图文编辑器，也不是登录页或验证码页。
- 百家号把配置的图文编辑器 URL 重定向到了已登录首页；原实现能够确认会话有效，但不会从首页重新进入图文编辑器，因此把可恢复的导航结果转成了人工处理。
- API 对浏览器网关的固定 15 秒等待时间短于 Browser Worker 的默认 30 秒页面导航时间，实时登录核验可能在浏览器返回明确结果前被 API 中止。

## 修复

- 发布直达 URL 落到已登录首页时，精确点击“发布作品”，再点击“图文”。
- 只有标题、正文和发布按钮同时可见时才确认进入编辑器并继续填稿。
- 导航后仍没有完整编辑器签名时继续返回 `PAGE_SIGNATURE_CHANGED`，停止在发布点击之前。
- API 浏览器网关等待时间默认调整为 65 秒，覆盖 Browser Worker 两次默认 30 秒导航窗口；可通过 `BAIJIAHAO_BROWSER_GATEWAY_TIMEOUT_MS` 配置，范围为 1–120 秒。
- 扫码完成和实时登录核验允许将明确的已登录首页作为有效会话，不要求直达编辑器同时可用。

## 安全边界

- 不把已登录首页当作可提交编辑器，不把导航成功当作发布成功。
- 不绕过登录、验证码或安全验证，不改变未知发布状态的对账和幂等规则。
- 不修改百家号内容、质量报告、质量门禁、排期或重试次数。
- 本 Hotfix 未访问生产百家号或生产官网。

## 部署与验收

- 重新构建并部署 API 和 Baijiahao Browser Worker；无需数据库迁移。
- 本地仿真覆盖编辑器直达 URL 回到首页、展开“发布作品”、进入“图文”并完成一次发布与内容列表对账。
- 部署后先恢复浏览器会话，再重试已确认未发布的任务；若仍失败，按新阶段、错误码和诊断截图继续核验，不得假定发布成功。
