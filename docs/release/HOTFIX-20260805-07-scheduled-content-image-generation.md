# HOTFIX-20260805-07 已排期内容手动生成配图

## 问题

- 已通过质量检查并进入排期的文章如果没有配图，发布任务详情页没有补生成入口。
- 既有配图事件只支持官网、百家号自动化运行，会继续推进自动化状态；直接复用会因人工排期任务没有自动化运行记录而失败。

## 修复

- 为官网、百家号中“已排期、尚未发布、当前内容版本无合格配图”的发布任务增加“生成配图”按钮。
- API 新增带幂等键和任务版本校验的配图生成接口；只接受当前内容版本、最新质量报告已通过、目标平台能够携带配图的排期任务。
- 手动触发复用既有 DeepSeek 配图规划、Cloudflare Workers AI 生图、安全检查、模板回退和 MinIO 存储链路，但不推进官网或百家号自动化运行状态。
- AI Worker 在开始生成前再次确认发布任务仍为已排期；任务已取消或已经开始发布时取消本次配图运行。
- 页面显示排队/生成状态，每 2 秒自动刷新；完成后展示配图数量。

## 冻结边界

- 不降低文章或配图的质量、品牌、事实、合规及来源门槛，不由服务端伪造模型质量结论。
- 不修改发布排期时间，不重新生成文章正文。
- 当前发布适配器只有官网和百家号会实际携带生成图片，因此其他平台不显示按钮，避免生成不会被使用的图片。

## 部署

- 重建并更新 API、AI Worker 和 Web。
- 不需要数据库迁移；历史已排期任务部署后会按当前内容版本和配图状态显示入口。
