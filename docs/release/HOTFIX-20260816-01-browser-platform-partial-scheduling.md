# HOTFIX-20260816-01 搜狐号与列举网日批部分排期提示

## 核验结果

- ADR-0037 已规定候选耗尽时先保留已合格文章并排期，再把未完成名额转为 `attention_required`。
- 搜狐号与列举网当前实现会在每篇文章通过冻结质量门禁后立即创建排期任务；批次进入
  `attention_required` 不会取消这些任务。
- 原提示只显示候选耗尽和目标数，没有显示已排期数与剩余缺口，容易被理解为整批阻断。

## 修复

- 候选耗尽提示明确显示已排期数量、剩余缺口和批次状态。
- 自动化配置页补充“已合格内容照常排期，未完成名额转为需要处理”的字段说明。
- 不改变候选生成、质量门禁、重写次数、排期任务或发布状态机。

## 部署

- 无数据库迁移。
- 重新构建并部署 Web 与 AI Worker。
