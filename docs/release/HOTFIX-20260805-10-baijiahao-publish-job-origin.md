# HOTFIX-20260805-10 百家号发布任务来源兼容

## 问题

发布任务 API 已支持 `baijiahao_automation` 来源，但 Web 发布日历的本地响应 Schema 仍只接受人工和官网自动化来源。只要列表中包含百家号自动发布任务，接口即使返回 200，Web 也会因响应校验失败而显示“无法加载发布日历”；发布任务详情存在相同问题。

## 修复

- Web 发布任务 Schema 补充 `baijiahao_automation`。
- 发布列表将该来源显示为“百家号自动化发布”。
- 发布详情将该来源显示为“百家号自动化创建”。
- 增加发布列表和详情的百家号自动任务回归测试。

## 部署

仅需重新构建并更新 Web 服务，无数据库迁移。
