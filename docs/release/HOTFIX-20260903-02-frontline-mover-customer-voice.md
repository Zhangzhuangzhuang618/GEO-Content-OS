# HOTFIX-20260903-02：抖音一线师傅客户化表达

- 状态：已完成
- 日期：2026-09-03
- 影响范围：抖音每日批次、AI Worker
- 前置决策：ADR-0074、ADR-0077、ADR-0081、ADR-0082

## 根因

ADR-0081 为防止虚构个人履历，把一线师傅口吻中的第一人称身份、工龄、亲历和案例全部作为高风险文本
处理。该边界同时压掉了“我到现场一般先看……”这类不含个人履历的通用工作方法，模型因此容易退化为
中性教程，甚至串成“选服务商时，我会……”的客户口吻。

## 修复

1. 一线师傅以约十年现场经验的判断成熟度面对客户说话；“十年”只是写作标尺，不得直接写成叙述者
   工龄。
2. 至少包含一次通用第一人称工作方法，并自然使用“你”或“您”给出具体动作。
3. 结尾由服务端使用品牌资料中的唯一法定企业全称，确定性组装“我就职于当前企业，欢迎联系我核对
   方案……”；企业名称不由模型猜测。
4. 确定性拦截客户选择身份、论文式套话、自报工龄、编造姓名和一次性亲历，只修复命中字段。
5. 师傅主文案按六个长短不同的自然段组装，减少八段等长说明书结构。
6. 输入引用直接记录官网公开案例或第三方经历时，允许简洁转述并要求可见事实与引用逐字映射；不得
   声称由叙述者亲手完成。没有进入 Writer Input 的网页不作为事实源。

## 事实边界

- 保险证明可支持其结构化摘要实际声明的投保主体、险种和人数，不能据此推导某位师傅有十年工龄。
- 企业成立年限、团队经验或网站宣传不能自动转换为叙述者个人履历。
- 如需公开具体工龄，后续必须提供可公开使用、能绑定账号人物并明确记载工龄的结构化资料；本 Hotfix
  不新增该资料类型。

## 验收

1. 一线师傅稿包含第一人称现场工作方法和直接客户称呼。
2. “选服务商时，我会……”及“放进备选名单”等客户口吻串线被局部修复。
3. 自报十年工龄和虚构本人经手案例继续被拦截。
4. 有引用的公开案例可通过，无引用案例停止或局部修复。
5. 最后一段准确使用当前企业名称和固定的任职、咨询表达。
6. AI Worker 单元测试、类型检查及一条完全合成资料的真实模型调用通过。
