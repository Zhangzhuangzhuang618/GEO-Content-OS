## 已确认原因与改动

- 硬广文章恢复为改写草稿时，`recommendationArticleFromContent` 将公司所有可用资料替换进引用列表，导致发布端要求正文出现未使用证照。改为保留该公司原引用与当前有效且归属正确的引用交集；缺失引用不静默替换为其他资料。发布端主体、授权、有效期、完整性和正文证照校验不关闭。
- 客户口吻首尾段固定词序误拒自然表达。兼容问明白、直接列入备选、等待实际报价再决定等表达；虚构经历、身份、归属等既有校验保留。
- 浅层抖音草稿中的合法文本允许在原上限四倍以内进入局部修复，最终仍按原字段上限及平台限制拒绝未修好的内容。标题、引用元数据、标签及结构规则不放宽。不截断正文或增加候选数量。
- Schema 错误增加字段路径、约束、长度限制及实际长度，反馈给结构修复并保留到最终错误消息；不记录字段正文。
