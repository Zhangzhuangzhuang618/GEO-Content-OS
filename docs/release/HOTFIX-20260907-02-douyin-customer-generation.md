# HOTFIX-20260907-02 抖音客户口吻生文失败修复

用户授权：依据生产失败诊断修复并部署；属于 T164 / ADR-0082 的生成质量 Bugfix。

## 生产证据

- 2026-09-07 客户口吻 33 个候选，26 个生文失败、3 个后续质检改写失败。
- 志远 24 个候选中 22 个生文失败，16 个包含证据映射为空；冻结输入没有授权证照或含本企业名称的引用。
- 候选 47700b10-f20c-4bd1-8193-5850c333f68f 的引用只有“搬迁费用4800元”和“赠价值500元保洁”，
  却被绑定“收费对比”标题；生产函数已复现，最终错误为标题承诺缺少对应可见映射证据。
- 客户口吻固定正则拒绝“我正在筛选”“我不考虑只给总价的公司”和“拿地址及清单出书面方案后再定”。
- 众人三个候选命中品牌禁词“最好”，随后整篇质检改写因首段格式不合格而失败。

## 修复与边界

1. 调度器和 Writer 共用收费对比证据判断：同一句中必须明确比较收费并有两项金额；赠品、券、补贴、
   立减、返现金额不计入。证据不足时调度器继续使用中性决策标题，不强制证据承诺。
2. 客户口吻识别增加筛选、询价、问清、明确拒绝及带地址清单核对书面方案后再决定的自然表达。
   已成交亲历、虚假评价、服务方身份、企业主体、长度及证据门禁保持不变。
3. 保留企业禁词配置及原质检规则；Direct Draft 中提前识别禁词并标记命中字段，使用原有有界局部修复，
   不为正常建议用语删除禁词，不由服务端直接改写正文。修复后仍有禁词时不得通过。
4. 统一首稿提示与证据门禁：有引用必须先选择能直接支持的相关事实并完成映射，不再暗示空映射能成功。
   无可用证据时仍失败关闭，禁止使用竞品推广或伪造资质凑数。

志远资料缺口未通过代码补造或跨企业借用：本次只读查询未找到该工作区的图片证照或名称包含志远的资料。
需要补充并授权真实企业资料后才能解决这一输入限制，不能承诺本次消除全部失败。

- AI Worker 全量 23 个测试文件 / 299 项单元测试、类型检查、生产构建、Lint 和静态发布检查通过；正反例覆盖赠品/优惠/单一区间/真实收费比较、客户口吻、
  禁词字段局部修复；既有证据、亲历、企业隔离和其他平台测试保持通过。
- 无数据库迁移、公开 API、前端、账号 Profile 或生产配置变更；只重建及替换 ai-worker。
- 部署前核对生产 HEAD、容器、API、日志和活动任务，保留旧镜像；从干净发布目录构建，保留服务器环境改动。
- 部署后核对新容器镜像、产物、健康和日志；保留历史失败，不自动重新生成、重新评估或发布。
- 回滚只需用保留的旧 AI Worker 镜像替换该服务，无数据库回退。
