# HOTFIX-20260806-20 百家号 AI 声明重渲染重试

## 真实页面证据

- 第二篇不同文章使用正式驱动时，在发布点击前的 AI 声明校验处阻断，远端未创建文章。
- 同一草稿重载后，原生 checkbox 一次点击即变为 `checked=true`，组件类同步为 `cheetah-checkbox-checked`，连续 8.6 秒不回滚。
- 这说明选择器和交互方式有效；失败发生在标题、正文、封面等表单刚更新后的组件重渲染窗口，第一次点击状态被替换。

## 修复

- AI 声明保持原生 checkbox 精确定位和强制点击。
- 每次点击前后都重新读取 `checked`，未生效时等待 100ms 再试，最多 5 次。
- 达到上限仍未选中时继续在发布点击前阻断。
- 浏览器仿真模拟第一次点击被 `preventDefault`，确保重试路径生效。

## 安全边界

- 不直接写 DOM 属性，不伪造 React 或组件状态。
- 重试仅作用于发布前的声明勾选，不重试发布按钮。
- 不放宽正文、图片、AI 声明、质量、幂等或未知态门禁。

## 部署与验收

- 重新构建并部署 Baijiahao Browser Worker；无需数据库迁移。
- 单元测试和浏览器回归必须保持通过。
- 第二篇必须由正式驱动返回平台成功确认并在内容列表可检索，才能满足连续两次成功验收。
