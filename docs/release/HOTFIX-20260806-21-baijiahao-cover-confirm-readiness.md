# HOTFIX-20260806-21 百家号封面确认按钮就绪态

## 真实页面证据

- 第二篇真实发布在封面上传弹窗中超时，发布按钮尚未点击，远端未创建文章。
- 上传文件后，“确定 (1)”会先以浅蓝色出现；此时点击不会关闭弹窗。稍后按钮切换为亮蓝色，才接受点击。
- 连续采样确认两个状态的 DOM、class、`disabled`、`aria-disabled`、光标和透明度完全相同，只有计算后的背景色从 `rgb(175, 195, 255)` 切换为 `rgb(56, 85, 213)`。

## 修复

- 封面确认按钮文本和数量出现后，继续等待真实页面的亮蓝可操作态，再执行一次确认点击。
- 超时未进入可操作态时返回 `PAGE_SIGNATURE_CHANGED`，停止在发布点击之前。
- 浏览器仿真把按钮文本出现与按钮可操作拆成两个阶段；浅蓝阶段的点击会被忽略，以覆盖本次故障。

## 安全边界

- 不使用固定等待时长推断上传完成。
- 不重复点击封面确认或发布按钮。
- 不放宽封面预览、质量、幂等、未知态或人工处理门禁。

## 部署与验收

- 重新构建并部署 Baijiahao Browser Worker；无需数据库迁移。
- 单元测试和浏览器回归必须保持通过。
- 第二篇必须由正式驱动取得平台成功确认，并在内容列表按精确标题检索到，之后才能统一推送本批 Hotfix。
