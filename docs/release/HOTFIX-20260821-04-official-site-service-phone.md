# HOTFIX-20260821-04 官网服务电话统一继承

## 修复内容

- 在企业资料中维护工作区级官网服务电话，发布管理只读继承。
- 官网首次生成、重写和人工保存均在落库前将当前电话合并到唯一 CTA。
- 官网质检和最终 Render 均校验当前电话恰好出现一次；其他平台不继承该证据。
- 缺少电话时不能启用官网自动化，日批保留为可恢复的需处理状态。

## 部署

1. 重建并部署 API、Web、AI Worker 和 Publisher Worker。
2. 在“企业资料”选择工作区，填写不含空格和连字符的官网服务电话。
3. 核对 PUB-01 官网自动化显示的继承号码，再启用或保存自动化策略。

## 旧数据

- 无数据库迁移，不自动修改旧内容、旧质量报告和旧发布任务。
- 旧内容若缺少当前电话、号码不一致或重复出现，需通过人工保存或重新生成产生新版本并重新质检。
- 更换电话后，绑定旧号码的旧任务会被最终发布校验阻断，不会带旧号发布。
