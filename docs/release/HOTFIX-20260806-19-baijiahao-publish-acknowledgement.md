- 点击发布前注册对 `POST /pcui/article/publish` 的响应等待，响应完成后才允许回查内容列表。
- 严格解析响应业务结构：必须是 `errno=0`，并包含 `article_id`、`id` 或 `nid` 中至少一个发布标识。
- 平台明确返回非零业务码时停止并进入人工处理，不将失败伪装成成功。
- 内容列表已同步时沿用列表结果；列表暂未同步时使用平台成功响应返回 `processing`，避免把已受理发布误报为未知态。
- 浏览器仿真改为返回同结构的发布确认响应。

## 安全边界

- 不直接调用发布接口；仍由真实发布按钮触发平台请求。
- 不把 HTTP 200 当作成功，必须校验平台业务码和发布标识。
