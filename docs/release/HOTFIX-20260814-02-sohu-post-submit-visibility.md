# HOTFIX-20260814-02：搜狐发布后列表可见性延迟

## 问题

搜狐接受图文发布后，内容管理列表可能短暂查不到新文章。单次即时对账会把已经进入审核的文章报告为 `PUBLISH_STATE_UNKNOWN`；稍后只读对账又能返回真实内容 ID 和 `processing` 状态，形成假失败。

## 修复

- 发布按钮只点击一次。
- 提交后最多执行 3 次内容列表对账，相邻尝试间隔 2 秒。
- 任一尝试得到 `processing | published | failed` 即返回；全部查不到才保留未知态。
- 对账轮询不重新填写内容、不重复上传图片，也不再次点击发布。

## 验证

- 本地搜狐浏览器仿真将内容列表可见时间延迟 500ms，验证首次查询为空后能够在后续查询取得结果。
- 第二篇经用户授权的真实文章已由搜狐接受，外部内容 ID 为 `1062685302`，只读对账状态为 `processing`，无失败原因。

## 发布与回滚

仅需重新部署 `sohu-browser` Worker。回滚本提交会恢复单次即时对账，并重新出现列表延迟导致的假失败。
