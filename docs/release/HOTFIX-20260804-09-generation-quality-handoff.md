# HOTFIX-20260804-09 重新生成后的质量链路恢复

## 问题

百家号候选通过人工入口重新生成后，新的内容版本已经保存，但原自动化运行仍可能停留在旧的生成、改写、质检、人工处理或已退役状态。后续人工质检虽然可以生成质量报告，自动化处理只接收 `quality_pending` 且内容版本完全匹配的运行，因此不会继续自动重写或排期。

质量报告页此前只有编辑和重新检查入口，无法直接重新生成失败内容。

## 修复

- 百家号手动重新生成成功后，重新绑定当前内容版本，将可恢复的自动化运行切换到 `quality_pending`，并自动投递质量检查。
- 支持恢复生成失败退役、自动改写失败、质量检查执行失败和达到最大重写次数后的候选；发布提交不明确等发布阶段故障仍禁止从内容入口恢复。
- 人工发起质量检查时，同步修复仍停留在生成、改写或旧质检状态的百家号运行，避免质量报告与自动化运行脱节。
- 官网派生内容每次使用当前正文重新计算来源相似度，继续执行冻结的相似度门禁，不复用旧版本结果。
- 质量报告页在阻断或需修改时增加“重新生成内容”按钮，保留锁定段落；官网和百家号生成后自动继续质检，其他平台按既有人工质检流程处理。

## 多平台核验

- 官网：生成存储层原本会按当前版本重新建立 `quality_pending` 运行并自动质检，没有同类断点。
- 百家号：存在自动化运行状态与手动重生成版本脱节，已修复。
- 头条号、知乎、小红书、微信公众号、抖音：当前未配置自动重写运行，既有契约是生成后由用户发起质检；质量报告页现可直接重新生成，不会形成无操作入口的死路。

## 冻结契约

- 未修改任何平台字数、结构、事实、品牌、合规、来源相似度或质量分数门槛。
- 未由服务端伪造模型质量结论；重新生成后的内容仍须经过现有机器质检和自动化门禁。
- 发布阶段故障不会被内容重新生成入口错误清除。
