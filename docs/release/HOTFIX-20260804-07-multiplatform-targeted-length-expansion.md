# HOTFIX-20260804-07 多平台字数不足定向续写

## 问题

百家号等通用平台版本在正文结构已合格、仅有效字符数不足时，原链路仍会整篇重写一次。整篇重写可能再次低于平台字数门槛，并覆盖已经合格的内容。

## 修复

- 复用官网定向续写机制：仅当全部剩余问题都是字数不足时触发，不做整篇重写。
- 保留标题、摘要、原有正文块、引用、CTA、标签和平台元数据，只追加 2–5 个实质段落或清单块。
- 按当前字数、冻结最低门槛和 30% 安全余量生成续写提示，最多执行两轮。
- 支持百家号、头条号、知乎、小红书、微信公众号、抖音，以及通用主稿和非直连官网版本。
- 多平台任务只扩写字数不足的平台版本，不覆盖其他已合格版本。
- 新增块去空、去重，引用 ID 必须来自输入资料；续写后仍不足则继续按 `CONTENT_QUALITY_INSUFFICIENT` 阻断。
- 保留 `fast` 策略原有的跳过生成阶段质量补救语义；自动发布使用的 `balanced` / `quality` 策略执行本修复。

## 冻结契约

- 未修改各平台现有字数、结构或质量门槛。
- 未伪造模型质量结论，最终结果仍由现有确定性评估和后续质量门禁判定。
- 未新增输入材料之外的事实或引用。

## 验证

- AI Worker 16 个测试文件、71 项测试通过。
- 新增六个平台逐项测试，确认原文保留、定向续写触发并达到原最低字数门槛；另验证多平台任务不会覆盖已合格版本。
- AI Worker 类型检查通过。
