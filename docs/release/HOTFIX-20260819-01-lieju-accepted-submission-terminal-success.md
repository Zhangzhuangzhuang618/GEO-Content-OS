# HOTFIX-20260819-01 列举网明确受理后完成发布任务

## 问题

列举网浏览器进入“信息审核中！”页面或官方 API 返回“信息发布成功”后，适配器仍返回
`processing`。Publisher 因而把任务留在 `publishing`。官方 API 没有后续状态查询能力，这类任务会
永久停在成功的中间态。

## 修复

- 浏览器命中精确“信息审核中！”确认页后直接返回终态成功。
- 官方 API 通过明确成功语义校验后直接返回终态成功，不再等待公开详情页可访问。
- 登录失效、验证码、明确拒绝、HTTP 5xx、网络未知和无法识别响应继续失败关闭或转人工处理。
- 不修改其他平台和冻结质量门槛。

这里的“成功”表示列举网已接受提交并进入平台审核，不表示平台审核已经通过。

## 部署与历史任务

重新构建并部署 Publisher Worker 和 Lieju Browser Worker；无需数据库迁移，也无需重新构建 Web 或
API。

部署前已经停在 `publishing` 的官方 API 任务不会自动重投。其内容 ID 和 URL 已保存，可通过现有
“确认已经发布”入口完成一次性收尾；部署后的新任务会直接完成。

## 验证

- 列举网官方 API Adapter 集成测试。
- Lieju Browser Worker 页面驱动集成测试。
- Lieju Browser Worker 单元测试、类型检查与构建。
- Publisher Worker 单元测试、类型检查与构建。
