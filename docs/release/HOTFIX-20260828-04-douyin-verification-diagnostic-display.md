# HOTFIX-20260828-04 抖音二次验证诊断展示修复

## 根因

T161 为防止手机号、二维码、头像和账号信息泄露，会在保存诊断截图前隐藏全部页面文字与背景图，并
遮盖输入框、图片及账号区域。PUB-01 又把该审计截图作为大幅操作画面展示，最终形成大面积深色遮罩，
容易被误判为抖音页面加载或渲染失败。

## 修复

1. PUB-01 不再渲染脱敏诊断截图，只展示挑战类型、无查询参数的页面位置、可用验证方式和诊断证据
   已安全保存提示。
2. 短信发送、验证码提交和原设备扫码入口保持不变；诊断截图继续按 T161 规则写入私有对象存储。
3. Web 浏览器测试明确断言：即使会话响应包含诊断图片，操作界面也不生成对应图片元素，并可继续
   完成短信二次验证。

## 不变边界

- 不返回或展示手机号、二维码、Cookie、账号身份信息、短信验证码或未脱敏页面。
- 不修改 Worker 状态机、截图遮罩、私有对象存储、登录快照、数据库结构、公开 API 或生产配置。
- 交互式验证码继续失败关闭，不识别、破解或绕过抖音风控。
