# HOTFIX-20260806-10 百家号发布后内容管理核验

## 生产证据

- `日志 (23).txt` 显示发布任务第三次尝试已完成编辑器填充和发布点击，随后在发布结果核验阶段返回 `PAGE_SIGNATURE_CHANGED`。
- 发布前截图中的标题、正文和发布按钮完整；失败截图是包含“发布作品”“内容管理”“个人中心”的已登录百家号首页，不是登录页或验证码页。
- 现有核验直接访问配置的内容管理地址。该地址落到已登录首页后，代码会转去登录页复核会话，最终只能报告“会话有效但目标页面不可用”，无法检查文章是否已经创建。

## 修复

- 发布后核验若落到已登录首页，通过页面中精确匹配的“内容管理”入口进入内容列表。
- 若“内容管理”先展开菜单，再按已有页面签名中的“作品管理”或“我的内容”进入列表。
- 移除把单独“内容管理”“作品管理”“我的内容”文本当成内容列表的宽泛判断；只有列表结构、表格或明确空列表状态才允许开始结果匹配。
- 已登录首页可直接通过登录态校验，但不能直接通过内容列表校验。

## 安全边界

- 不把跳回首页、点击导航或会话有效当作发布成功。
- 仍需在内容列表中按标题、内容指纹和提交时间找到唯一记录；找不到返回状态未知，多条匹配进入人工处理。
- 不绕过登录、验证码或安全验证，不改变外部发布幂等和人工确认策略。
- 当前第三次尝试的真实发布结果仍需在百家号内容管理中核对后再决定标记已发布或允许原幂等键重试。

## 部署与验收

- 重新构建并部署 Baijiahao Browser Worker；无需数据库迁移。
- 用已登录会话验证：配置的内容管理地址落到首页时，Worker 应进入内容列表并核验唯一文章。
- 若列表仍不可达，应保留新的 `PAGE_SIGNATURE_CHANGED`、页面地址和截图继续诊断，不得假定发布成功。
