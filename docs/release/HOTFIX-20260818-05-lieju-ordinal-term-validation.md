# HOTFIX-20260818-05 列举网普通序数误判修复

## 问题

列举网发布前校验使用 `第一(?!方)` 阻断排名宣传，导致“第一步：盘点物品”等普通流程表达被误判为
`PROHIBITED_TERM`。任务在 Publisher 渲染阶段失败，没有调用列举网官方 API。

## 修复

- 将裸“第一”匹配收窄为明确排名或营销语境。
- 放行“第一步、第一阶段、第一时间、第一年”和既有“第一方”。
- 继续阻断“行业第一、排名第一、第一品牌、自称第一”等排名宣传，以及其他既有高风险宣传词。

## 安全边界

- 不降低冻结质量门槛，不修改模型质量结论或旧质量报告。
- 不自动重试旧任务，不调用生产列举网；部署后需人工从原发布任务点击普通“重试”。
- 不改变列举网官方 API、防重复提交预留或未知态人工核实规则。

## 部署

重新构建并部署 Publisher Worker。无数据库迁移；API 和 Web 无需因本 Hotfix 重建。
