# HOTFIX-20260819-03 列举网发布资料修复

## 根因

生产响应并非 API Key 或登录态错误，而是列举网拒绝了该 GEO 账号独立保存的微信号。旧编辑页无法
更新或清空微信号，错误值因局部合并逻辑被持续继承。同一个 API Key 下的另一个账号使用不同的
加密发布资料，因此可以正常发布。

## 修复

- 列举网账号编辑页可局部更新区域、地址、联系人、电话、QQ 和微信号。
- QQ、微信号新增显式清空选项；空白输入仍表示不修改，所有已保存值继续不回显。
- 创建、编辑及 Adapter 最终配置统一校验列举网当前电话、QQ、微信号格式。
- 旧错误资料在外部请求发出前记为明确账号配置失败，不再错误进入发布状态未知。
- 列举网当前“请正确填写微信号”等联系方式提示改为明确发布拒绝，不再误报状态未知、登录问题或
  API 权限问题。
- 不改变 API Key 保存、未知态防重复、冻结质量门槛或发布成功判定。

## 部署与旧数据

- 无数据库迁移。
- 重新构建并部署 Web、API 和 Publisher Worker。
- 旧账号资料不会自动改写。部署后在“发布管理 → 平台账号 → 修改账号”中勾选“清空已保存的微信号”
  或填写正确新值，再保存。
- 旧失败任务不会自动重投。若旧任务是未知结果，必须先在列举网后台确认未发布，再走原任务恢复
  入口；仍有普通重试次数的明确失败任务可在资料修正后重试。

## 验证

- 列举网 Adapter 测试：184/184 通过。
- Web 请求层测试：3/3 通过。
- 平台账号 API 集成测试：8/8 通过。
- Web、API、平台 Adapter 类型检查通过。
- 发布管理页面级回归覆盖资料更新与微信号清空。
- Publisher 集成回归覆盖错误资料落为 `rejected`，而非 `manual_required`。
