# HOTFIX-20260806-02 百家号正文图片就绪判断修复

## 生产证据

- 正文图片弹窗已显示“2张上传成功”，两张缩略图均已出现。
- 真实正文弹窗的确认按钮文本始终是“确认”，不包含图片数量。
- `756d4f4` 错误复用了封面按钮的“确定（数量）”规则，导致 `upload_body_images` 等待不存在的“确认 (2)”并在 30 秒后超时。

## 修复

- 封面继续等待“确定（数量）”，该数量来自真实封面弹窗。
- 正文图片改为等待“X张上传成功”，随后点击无数量后缀的“确认”或“确定”。
- 浏览器仿真保持正文按钮无计数，并延迟显示上传成功状态，覆盖真实异步上传过程。

## 安全边界

- 未出现与本次图片数量一致的上传成功状态时，不点击确认、不继续发布。
- 正文图片未实际插入编辑器时，仍由后续 DOM 核验阻断发布。
- 不改变登录态、质量门禁、幂等键和远端发布结果判定。

## 验收

- 两张正文图片上传完成后可以点击无计数的“确认”并插入正文。
- 封面图仍必须等待带数量的确认按钮。
- 图片上传失败或数量不一致时继续失败关闭。
