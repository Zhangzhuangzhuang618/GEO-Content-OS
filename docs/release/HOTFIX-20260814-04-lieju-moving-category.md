# HOTFIX-20260814-04：列举网搬家分类修正

## 问题

列举网 Worker、账号配置页面和生成提示词误把目标发布分类固定为“商务服务 → 物流/货运” `/5/104`。业务要求和真实平台页面应为“生活服务 → 搬家” `/5/73`，继续使用旧入口会把搬家内容投递到错误分类。

## 修复

- 默认编辑页改为 `/5/73`，并同步 Web 后台跳转地址和 Compose 默认值。
- 账号发布配置改用平台真实搬家子类：空调拆装、公司搬家、设备搬迁、搬家搬场、长途搬家、起重吊装。
- 列举网生成提示词改为广州搬家分类信息；既有 `content_type=logistics_freight` 仅作载荷兼容标记，不改变质量门禁。
- 提交后的页面跳转判断改为比较实际配置的编辑页路径，不再硬编码旧路径。
- 图片选择后，真实页面会生成预览并清空文件输入框；Worker 改为接受“文件仍在输入框”或“已生成非空预览”两种成功状态，仍在出现上传错误或两者均不存在时失败关闭。

## 兼容与风险

- 旧账号的 `category_id` 1–6 会按新搬家子类解释，部署后应在账号配置中复核具体子类。
- 旧值 7 在搬家表单无对应选项，配置校验会失败关闭，必须重新选择后才能发布。
- 不修改已生成内容、旧质量报告或既有发布记录，不降低质量阈值。

## 发布与回滚

重新构建并部署 Web、API、Publisher 与 `lieju-browser` Worker。回滚本 Hotfix 会恢复错误的物流/货运分类，不建议在存在待发布列举网任务时回滚。
