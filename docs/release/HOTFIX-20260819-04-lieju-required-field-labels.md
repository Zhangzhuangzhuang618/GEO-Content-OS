# HOTFIX-20260819-04 列举网必填资料标识

## 问题

列举网官方 API 账号表单虽然已在提交时校验必填资料，但页面只通过输入控件的 `required` 属性约束，
没有直观说明哪些字段由列举网要求必填。编辑页又因加密资料不回显，容易把“留空沿用旧值”误解为
字段可选。

## 修复

- 新建列举网官方 API 账号时，将 API Key、广州区域、发布地址、联系人和联系电话标为
  “列举网必填”。
- QQ 和微信号继续明确标为可选。
- 编辑账号时使用相同标识，并说明必填资料必须已存在于账号配置；留空表示沿用已保存值，无需重复
  填写或暴露加密资料。
- 不改变字段校验、凭据保存、发布请求、质量门槛或历史任务状态。

## 部署与验证

- 只需重新构建并部署 Web，无数据库迁移。
- Web 类型检查、生产构建、定向 ESLint/Prettier 检查通过。
- PUB-01 Chromium 回归覆盖新建和编辑场景，2/2 通过。
