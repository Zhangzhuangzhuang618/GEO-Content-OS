# HOTFIX-20260816-03 全平台自动化账号自动排期

## 问题

- HOTFIX-20260816-02 只移除了百家号的手工发布时间输入。
- 搜狐号和列举网仍要求用户填写与每日目标等量的逗号分隔时段，平台体验和保存约束不一致。

## 修复

- 将自动时段生成器改为全平台自动化账号共用。
- 搜狐号和列举网根据每日目标自动生成并只读展示发布时间，不再接受手工时段。
- 官网仍使用冻结的固定十时段；百家号继续使用上一 Hotfix 的自动时段。
- 每日目标为 1 时使用 `10:00`，目标为 10 时使用官网固定十时段，中间目标均匀取样。
- API 仍保存明确的 `daily_schedule_times`，Worker 排期、幂等和状态机不变。
- 不修改质量门槛、候选上限、重写次数或发布规则。

## 范围说明

- 当前具备全链路日批的账号为官网、百家号、搜狐号和列举网，本次修改后均无需手填发布时间。
- 头条号、知乎、小红书、微信公众号和抖音目前没有全链路日批策略，不在本 Hotfix 中扩展。

## 部署

- 无数据库迁移。
- 重新构建并部署 Web。
