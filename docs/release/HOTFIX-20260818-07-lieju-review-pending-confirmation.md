# HOTFIX-20260818-07 列举网审核确认页提交回执

## 问题

列举网浏览器发布提交成功后会进入“信息审核中！”确认页。Worker 已能看到页面中的“审核”文本，
但仍立即进入会员中心按标题对账；平台尚未把新内容加入管理列表时，Worker 会连续查询后报
`PUBLISH_STATE_UNKNOWN`，把已被平台接受的提交误记为失败或未知。

## 修复

- 将精确文本“信息审核中！”作为平台已接受提交、等待审核的明确回执。
- 命中该页面后立即结束本次提交等待并返回 `processing`，不再要求标题已出现在会员中心。
- 平台尚未提供内容 ID 时不伪造远端 ID；对外继续使用本地发布记录 ID，并由既有状态查询按标题
  对账。
- 后续平台生成真实内容 ID 时仍保持本地对账 ID 稳定，避免 Publisher 的已排期对账事件因标识中途
  变化而失配；公开链接仍以平台实际结果为准。
- 只有会员中心出现公开链接且公开页可访问、标题匹配时，才把任务更新为 `published`。

## 安全边界

- “信息审核中”不等于公开发布成功，不生成公开 URL，不跳过后续审核状态对账。
- 发布失败、验证码、登录失效、页面签名变化和多条标题匹配仍按原规则失败关闭或转人工处理。
- 不修改冻结质量门槛、旧内容、旧质量报告或历史发布尝试。

## 部署与恢复

重新构建并部署 Lieju Browser Worker。无需数据库迁移，API、Web 和 Publisher 无需因本 Hotfix
重建。部署后新提交会在进入“信息审核中！”页面后立即成为 `processing`；既有失败任务不会自动
改写，仍需按当前人工核实和重试流程处理。
