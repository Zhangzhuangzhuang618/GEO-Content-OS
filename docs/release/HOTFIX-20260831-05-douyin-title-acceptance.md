# HOTFIX-20260831-05 抖音搜索意图标题验收与补位

## 根因

2026-08-31 已发布和待发布内容复核表明，原日批只把“地域＋具体场景＋决策问题”写入提示词，服务端仅
校验标题是否含搜索意图词，没有验收地域与场景。标题证据规则只会拦截无支持的证据承诺；检索已经找到
匹配证据时，也没有要求标题和正文实际使用该证据。日批重启后候选序号又从 1 开始，补位可能重复当天
已经尝试的主题。

## 修复

1. 从关键词导入元数据读取地域和场景；地域为通用时使用项目关键词中的主地域，形成服务器绑定的标题
   主体。生成、定点修复和质量重写均要求标题逐字保留该主体。
2. 只在检索证据与当前决策意图明确匹配时绑定 `资质核验`、`合同条款解读`、`收费对比` 或
   `真实场景`。绑定后标题必须逐字保留承诺，正文必须提供对应可见事实并通过已提供引用完成证据映射。
3. 新增确定性验收：搜索意图、标题主体、证据承诺以及承诺对应的可见证据映射任一不满足，内容不得
   进入排期。证据不足时进入完整草稿修订，不允许删除服务器绑定承诺或强配引用。
4. 当天编辑序号跨日批尝试累计。补生成继续轮换后续关键词和决策意图，不从第一个主题重复开始。

## 生产补位边界

- 不修改或删除已经发布的抖音作品。
- 仅撤销尚未发布、尝试次数为 0 且无发布尝试/远端发布记录的不合格排期，保留原任务、批次项和审计
  历史，再按当天剩余名额补生成。
- 无数据库迁移、公开 API、环境变量或 Compose 变化；只需重建 `ai-worker`。
- GEO、事实、品牌、可读性、安全、问题覆盖和平台适配门禁均不降低。
