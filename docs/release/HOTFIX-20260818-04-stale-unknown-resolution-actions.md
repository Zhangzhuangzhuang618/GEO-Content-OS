# HOTFIX-20260818-04 过期未知发布处置入口

## 问题

浏览器平台发布尝试进入未知态后，PUB-03 只根据任务状态、最新尝试和剩余尝试次数展示人工处置按钮。
当用户随后对同一内容发起重新质检，内容变体已经离开 `publish_failed`，旧发布任务仍会错误显示
“确认未发布并重试”。处置事务会正确拒绝该请求并返回 409，导致页面提供一个必然失败的操作。

## 修复

- 详情接口读取内容变体状态和当前内容版本，与处置事务共用未知发布状态判断。
- 任务仍处于 `publish_failed` 且指向当前内容版本时，保留“确认未发布并重试”、达到上限后的
  “确认未发布并结束任务”以及带公开链接的“确认已经发布”。
- 内容已经进入重新质检、其他处理流程或产生新版本时，保留历史未知态说明，但不再展示三个过期
  处置按钮，也不回退到普通“重试”按钮；页面明确提示用户处理当前内容状态或当前版本任务。
- 公开响应增加可选的脱敏阻断原因 `content_state_changed | content_version_changed`，同步更新
  Contracts、OpenAPI 和 Web 响应校验。

## 安全边界

- 不把未知发布结果改成普通重试，不绕过列举网提交预留或浏览器平台防重复保护。
- 不修改发布尝试上限、冻结质量门禁、旧任务、旧发布记录或旧质量报告。
- 处置事务仍在写入时重新校验版本和外部发布记录；详情结果不替代事务并发保护。

## 部署

重新构建并部署 Contracts、API 和 Web。无需数据库迁移，也无需重建 Publisher 或浏览器 Worker。
