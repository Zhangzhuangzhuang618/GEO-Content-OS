# HOTFIX-20260902-02 官网与列举网日批使用已发布品牌 CTA

## 根因

官网日批把 `brief.constraints.cta` 固定为 `null`，列举网日批使用固定占位文案。品牌策略发布新 CTA 或退役旧
版本后，这两条自动化链路仍不会采用当前已发布版本。

## 修复

1. 官网日批从当前工作区最新已发布品牌资料读取 CTA，并冻结到候选 Brief。
2. 列举网日批采用同一已发布品牌 CTA，不再使用固定占位文案。
3. 品牌 CTA 为空时保持为空，不回退到退役版本。
4. 搜狐号、抖音和百家号的 CTA 规则不变。

## 验证范围

- 官网日批集成测试检查生成事件中的 CTA 快照。
- 列举网与搜狐号集成测试分别检查品牌 CTA 和空 CTA。
- AI Worker 类型检查、格式和 Release static gate。
