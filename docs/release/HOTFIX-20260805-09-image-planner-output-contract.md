# HOTFIX-20260805-09 配图规划输出契约

## 问题

- AI Worker 已成功恢复历史配图任务，但 DeepSeek 连续返回无法通过本地结构校验的 JSON，配图规划报 `Image plan shape is invalid`。
- 原提示词要求返回“指定 JSON”，却没有给出 `cover_label`、`scenes`、`caption` 和 `prompt` 的实际结构；代码同时强制要求 `scenes` 恰好包含两个对象，模型与解析器契约不完整。
- 规划失败只有通用错误，无法判断模型返回的顶层字段和场景数量，Cloudflare 因此没有收到生图请求并直接走模板兜底。

## 修复

- 在首次规划提示词中明确唯一 JSON 结构、字段名称、字段长度和恰好两个场景，禁止包裹字段、Markdown 和额外说明。
- 首次响应未通过本地校验时，只执行一次零温度格式修复；修复请求携带原始文章输入、脱敏校验错误和首次模型输出。
- 修复结果重新执行原有结构、字段长度、公司名称、联系方式、二维码、价格和证据冒充门禁；第二次仍不合格时继续使用模板兜底。
- `plan_json.plannerDiagnostics` 保存调用次数、是否修复、响应字符数、SHA-256、顶层字段、场景数量和最多 2000 字符的脱敏预览。
- 诊断预览会替换其他公司名称、URL、手机号及常见密钥字段，不向公开文章或发布载荷写入模型原始响应。

## 冻结边界

- 不降低配图规划或图片视觉质检门槛，不绕过确定性安全检查。
- 不修改文章正文、文章质量报告和发布门槛。
- 最多增加一次规划修复调用；模型请求自身的网络重试策略保持不变。

## 部署

- 只需重建并更新 AI Worker。
- 不需要更新 API、Web、Publisher、百家号浏览器或数据库结构。
- 已经完成为 `fallback` 的历史配图运行不会自动重跑；使用新的自动化文章或无配图的已排期任务验证。

- AI Worker 类型检查通过。
