# HOTFIX-20260806-12 百家号正文编辑器状态注册

## 真实发布证据

- 封面完成态修复后，本地真实发布的发布前截图显示标题、正文和生成封面均可见，但编辑器底部仍显示“字数 0”。
- 点击发布后内容管理没有创建文章，核验返回 `PUBLISH_STATE_UNKNOWN`。
- 随后通过标题搜索检查“全部、已发布、待发布、未通过、已撤回、草稿”六个状态，均不存在目标文章。
- 现有驱动对 iframe 内的 `contenteditable` 正文使用 Playwright `fill()`；该操作改变了可见 DOM，但没有触发百家号富文本编辑器用于字数和发布载荷的键盘输入状态。

## 修复

- 正文改为聚焦编辑器、全选并通过真实键盘事件序列输入，触发百家号富文本编辑器内部状态更新。
- 输入后对规范化正文执行完整一致性校验，避免字符丢失或截断。
- 若页面仍显示“字数 0”，在点击发布前返回明确的 `PAGE_SIGNATURE_CHANGED` 并停止。

## 安全边界

- 不通过直接改 DOM、注入编辑器状态或伪造字数绕过平台校验。
- 不降低正文、图片、质量或发布幂等门禁。
- 真实发布结果不明确时仍停止自动重试，必须先查询全部内容状态。

## 部署与验收

- 重新构建并部署 Baijiahao Browser Worker；无需数据库迁移。
- 浏览器回归模拟只有键盘事件才能更新字数的富文本编辑器；提交时必须确认正文已注册。
- 真实灰度必须在发布前截图中确认字数不为 0，再允许一次提交动作。
