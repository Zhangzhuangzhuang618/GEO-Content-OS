# HOTFIX-20260816-02 百家号自动生成排期时段

## 问题

- 百家号自动化会自动执行排期，但管理界面要求发布时间数量与每日目标一致，并让用户手工输入逗号
  分隔的时段。
- 每日目标从 1 调整为 10 时，原单篇默认值 `10:00` 不会自动补齐，容易被误解为需要逐篇手工
  排期，也会阻止策略保存。

## 修复

- 百家号发布时间改为按每日目标自动生成，界面只读展示最终时段，不再接受手工输入。
- 每日目标为 1 时保留原默认 `10:00`；目标为 10 时使用官网冻结的十个北京时间；中间目标在
  同一组时段内均匀选取。
- API 仍保存明确的 `daily_schedule_times`，AI Worker 的排期、幂等和状态机不变。
- 不修改质量门槛、候选上限、重写次数或浏览器发布规则。

## 部署

- 无数据库迁移。
- 重新构建并部署 Web。
