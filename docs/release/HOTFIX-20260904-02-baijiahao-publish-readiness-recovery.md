# HOTFIX-20260904-02 百家号发布就绪状态恢复

- 状态：已完成
- 日期：2026-09-04
- 影响范围：Baijiahao Browser Worker
- 前置决策：ADR-0028、HOTFIX-20260903-01

## 生产证据与根因

1. 志远百家号的失败截图明确显示“您的账号已被封停”。这是百家号账号限制，不是登录失效或页面选择器
   故障，系统只能识别并停止发布，不能通过代码解除。
2. 众人搬家百家号的失败截图显示标题、正文、图片、封面和当前“智能创作”区域均已正常出现。该失败发生
   在 HOTFIX-20260903-01 支持当前编辑器签名之前；新版本可以通过人工“检查恢复”把会话恢复为
   `authenticated`。
3. 定时发布仍会在打开浏览器前无条件拒绝所有 `attention_required` 会话。因此，页面适配或浏览器运行时
   故障已经修复后，账号仍可能因旧的技术暂停错过后续排期，直到人工触发状态检查。

## 修复

1. Browser Session 内部读取既有 `last_error_json`，不新增数据库字段或迁移。
2. 仅当暂停原因是 `PAGE_SIGNATURE_CHANGED`、`EDITOR_OPERATION_FAILED` 或
   `BROWSER_RUNTIME_FAILED` 时，下一次定时发布先执行一次只读的发布就绪复核。
3. 复核通过后刷新加密登录态、清除旧错误并恢复为 `authenticated`，然后继续原发布流程。
4. CAPTCHA、账号封停和其他人工状态不进入自动恢复。复核期间发现账号封停时，将原因更新为
   `ACCOUNT_RESTRICTED`，并在创建发布记录和填写正文前返回 423。

## 边界

- 不修改公开 API、数据库、环境变量、Docker Compose、内容质量门禁或发布幂等规则。
- 不自动重试已经进入终态的历史发布任务，不重新生成历史内容。
- 不解除百家号平台侧封停；志远账号恢复发布前仍需在百家号申诉并解除限制。

## 验证

- Baijiahao Browser Worker 单元测试：技术暂停恢复、账号限制保持阻断、原有发布与对账路径。
- Baijiahao 本机浏览器仿真：当前“智能创作”编辑器、账号封停弹窗、发布与内容列表对账。
- TypeScript 类型检查、ESLint、格式检查、生产构建和 Release static gate。
