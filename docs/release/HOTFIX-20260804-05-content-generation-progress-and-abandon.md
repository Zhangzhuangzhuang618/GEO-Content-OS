# HOTFIX-20260804-05 内容生成状态、进度与失败任务放弃

## 问题

- 内容列表把尚未开始的 `draft` 显示为“准备生成”，用户无法判断任务是在排队还是正在执行。
- 原进度条只显示已生成平台数量，生成期间没有活动反馈，也不会自动读取最新状态。
- 生成全部失败后，列表页只能重试或复制，不能直接放弃任务。

## 修复

- `draft` 明确显示为“等待开始”，主操作改为“开始生成”，并说明任务尚未开始。
- `generating` 显示动态活动条、已完成平台数和具体平台状态。模型不提供内部百分比，因此不伪造精确进度。
- 仅当当前页存在生成中任务且页面可见时，每 15 秒低频刷新一次内容列表；后台刷新失败不会覆盖已加载内容。
- `all_failed` 卡片为内容生产角色增加“放弃任务”按钮，要求填写审计原因，并复用现有受权限、版本和活跃运行保护的放弃接口。

## 契约与部署

- 未修改质量门槛、生成结论或状态机。
- 未新增 API 或数据库迁移。
- 仅需重新构建并部署 Web；API 和 AI Worker 无需因本 Hotfix 重建。
