# HOTFIX-20260902-01 企业基础资料默认可选

## 根因

官网、列举网的生成器和 Publisher 把“至少一份基础资质或保障资料”设成所有工作区的统一前置条件。
该条件只适合已配置搬家行业资料包的企业，会使其他行业或尚未配置可选资料的企业在零候选处失败。

## 修复

1. 未配置工作区必需资料类别时，允许基础资料集合为空。
2. 仅在存在有效基础资料时向 Content Writer 注入 `enterprise_evidence`，并确定性插入资质保障内容和
   引用映射。
3. 无基础资料时明确禁止模型补造证照、认证、保险和赔付事实。
4. Publisher 对未配置资料的工作区放行；工作区显式声明必需类别时继续失败关闭。
5. 手工生文、官网日批和列举网日批采用同一可选语义。

## 验证范围

- 官网无基础资料日批集成测试。
- 列举网无基础资料日批集成测试。
- Publisher 无资料放行与显式必需类别阻断测试。
- API、AI Worker、Publisher 类型检查和相关测试。
- Release static gate 与生产健康检查。
