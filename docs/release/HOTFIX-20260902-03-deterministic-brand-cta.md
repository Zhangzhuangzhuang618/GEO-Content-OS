# HOTFIX-20260902-03 官网与列举网最终 CTA 确定性固定

## 根因

日批已把当前已发布品牌 CTA 写入生成输入，但通用 Content Writer 仍允许模型返回自己的 CTA。列举网部分候选因此缩写了品牌 CTA；官网发布层还会按既有规则追加企业服务电话，不能用最终字符串完全相等判断输入快照是否生效。

## 修复

1. 官网与列举网平台变体完成模型输出规范化后，由服务端用生成输入中冻结的 CTA 覆盖模型返回值。
2. 确定性覆盖发生在企业资料段落组装和质量检查前，正文与发布门禁使用同一 CTA。
3. 其他平台不受影响；官网发布层追加已确认服务电话的既有行为不变。

## 验证范围

- Content Writer 单元测试模拟模型主动缩写列举网 CTA，验证最终变体仍逐字采用配置值。
- AI Worker 类型检查、格式、Lint 和 Release static gate。
- 生产补生成后分别核验列举网 CTA 原文和官网 CTA 加服务电话的最终内容。
